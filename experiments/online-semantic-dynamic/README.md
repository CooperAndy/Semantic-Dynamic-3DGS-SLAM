隔离候选为`candidate_v4_fp64accum`，私有光栅化扩展为`raster_fp64_accum_v1`。修复CUDA梯度累加的数值波动，保留原优化器、学习率、相机约定、输入分辨率、每帧3000点上限与60次建图更新。FP64临时缓冲为每高斯88字节，开销纳入实测。
