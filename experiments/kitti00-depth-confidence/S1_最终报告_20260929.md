# S1 深度置信度筛选消融：五档更新报告

更新日期：2026-09-29  
范围：KITTI sequence 00，帧 `000000–000199`  
状态：**`S1_FIVE_THRESHOLDS_COMMON_SUPPORT_COMPLETE`**。原 `0.60/0.70/0.80/0.90` 四档于 2026-09-17 完成；`0.50` 是 2026-09-29 的后补实验，不属于原四档预登记范围。

## 1. 结论

**继续推荐 `T=0.60` 作为本序列、质量优先口径下的默认值。**五档在相同评价支撑上比较时，0.60 的平均整图 PSNR、MS-SSIM、LPIPS 和原始 RAFT 深度 L1 均为五档最佳。0.50 让 eligible seed 增加约 946.6 万个，但统一深度覆盖仅增加 `0.0483` 个百分点，四项平均质量均低于 0.60。0.50 的地图更小、运行更快，可作为成本受限场景的后续候选；单次运行不足以证明这种成本优势会跨种子稳定复现。

这不是所有阈值、所有场景的全局最优证明。0.50 与 0.60 的逐帧 PSNR 各有 5 帧更好；本次选择依据是冻结评价协议下的平均质量、覆盖和成本顺序。

## 2. 冻结输入与评价协议

- 输入：KITTI seq00 前 200 帧；同批左目 RAFT 深度和置信度；有效深度为 `0.5–40 m`；相同的外部 ORB-SLAM3 **估计位姿**、相机标定、`seed=0` 和 SplaTAM 参数。
- 门控：`eligible(T) = valid_depth AND confidence >= T`。eligible 是 Gaussian 种子资格，不等于最终地图中的 Gaussian 数。
- held-out：帧 `19,39,59,79,99,119,139,159,179,199` 不参与建图。
- RGB：每档都在整幅 `376×1241` 图像上评价；深度：每档都在相同的原始 RAFT 有效深度像素上评价；覆盖：silhouette `>0.5`。
- T=0.50 的 200 个置信度和 200 个深度输入文件与原 S1 清单 **400/400 SHA-256 相同**；复算 T=0.60 的 200 帧 eligible 计数也逐帧相同。
- T=0.50 沿用原统一支撑脚本与原始 RAFT 评价配置，SHA-256 分别为 `e0338da2cef30c8faed1faa1df2d80de435c6b3b534d5b8e971fd92e964e2db7` 和 `d7388f351ab59730c16e416af381741ee659dc31dc9fd20c16e1068ac113a8c1`。

旧 SplaTAM 内置评价会用各阈值自己的 hard-depth mask 同时限制 RGB 和深度统计。各档评价区域不同，旧 PSNR 等只作协议诊断，**不得用于阈值排名**。下表的 Depth L1 对比目标是原始 **RAFT pseudo-depth**，不是 LiDAR ground truth。

T=0.50 相比 0.60 的平均差值为 PSNR `−0.1853 dB`、MS-SSIM `−0.00970`、LPIPS `+0.02136`、Depth L1 `+0.1426 m`、覆盖 `+0.0483` 个百分点。10 帧配对下，T=0.50 的 PSNR 为 5 胜 5 负，LPIPS 为 3 胜 7 负，Depth L1 为 3 胜 7 负。20,000 次配对帧 bootstrap 的描述性 95% 区间：PSNR 差 `[−0.471,+0.080] dB`、LPIPS 差 `[+0.0078,+0.0353]`、Depth L1 差 `[−0.009,+0.344] m`。区间只反映这 10 帧的波动，不覆盖跨种子或跨序列变异。
