## 先验数值门槛

使用原 T14 的同一真实 L1：RGB绝对残差和权重0.9，深度绝对残差和权重0.1；深度残差截断1000。支持在 T0 固定，包含有效观测深度(0,8)、静态区域、初始渲染有限深度、opacity>0.95，并去除10像素边界；支持不少于1000像素。

局部坐标尺度 S 为平移0.02m、旋转1°。实际 L1 中央差分的归一化 h 固定为0.001、0.002、0.004，以0.002为主检查。数值门槛在首个 GPU 检查前登记：

| 检查 | 门槛 |
|---|---|
| 解析梯度与主尺度 L1 中央差分相对 L2 差 | ≤0.15 |
| 两梯度夹角余弦 | ≥0.98 |
| 另两尺度 FD 梯度相对主尺度最大差 | ≤0.20 |
| ID/FULL 方向导数与主尺度 FD | 同号且相对差≤0.15 |
| H差分尺度乘0.5/2后 P 相对 Frobenius 差 | ≤0.20 |
| H差分尺度乘0.5/2后 Pg 方向余弦 | ≥0.98 |
| 初始 forward 重复、地图和 RNG | 逐项一致 |

H/P 沿用 T14：RGB/D残差中央差分，基础物理 eps=0.001m/0.01°，H为加权Jacobian Gram，trace/6归一化，阻尼0.01，逆平方根P的Frobenius范数设为sqrt(6)。三尺度都保存 H 和 P。任一快照未通过任一门槛，停止8个回放，先诊断数值原因；不放宽门槛。

这些门槛是本轮 DEV 数值一致性门槛，不是统计置信度或正式质量验收。

## 条件回放

1. LOCAL_ID：P=I。
