# T3-DG-T05：各向同性首轮旋转更新消融

日期：2026-10-11。研究方向：利用3D高斯的表示与渲染特性改善tracking／mapping。

## 1. 当前状态

**T05已完成，工程完整性PASS，预登记机制门槛NOT_MET；候选不采用。** 原策略与候选各3次固定输入首次建图，共6000次优化器调用、6000次优化render、144次prune，以及6次最终完整地图render。

跳过首轮rotation确实消除了这一轮的旋转更新，随后旋转正常恢复。但候选组内RGB渲染波动仅降低1.51%，深度渲染波动增加10.32%，均未达到至少降低20%的门槛。训练观测拟合基本不变。这不支持把“只跳过各向同性首轮旋转”作为有效稳定化策略，也不能据此把全部分岔归因于该首步噪声。

GPU实际建图计时合计298.216秒，计算已结束，实例未关闭。没有执行完整轨迹ATE或独立几何质量评价；保留负结果与原基线。

## 2. 机制直觉与唯一干预

T04的初始12185个高斯三轴尺度完全相等、四元数均为单位旋转。其协方差为：

\[
\Sigma=R\operatorname{diag}(s^2,s^2,s^2)R^T=s^2I.
\]

此时旋转无法改变高斯形状，理论上没有旋转方向的信息。T04却观察到微小且跨次不稳定的旋转梯度；Adam的归一化可能把它转为实际旋转更新。本轮直接记录实际首步更新，检验只跳过这一步能否减少后续建图波动。

候选`SKIP_ROT0`只在第一段`optimize_cur_map`第0轮，把rotation叶参数的`.grad`暂设为`None`，调用原Adam，再恢复保存的梯度，继续作者的清梯度流程。要求该步rotation原参数完全不变、Adam状态与step均未分配；其他五组照常更新。第1轮起恢复正常旋转更新，第二段使用作者新建的Adam。没有永久关闭旋转，也没有把“梯度清零但动量仍更新”当作冻结。

**这一干预还使候选第一段rotation的Adam偏差校正计数比原策略晚一步。** 因而最终差异是上述完整策略的效果，不能单独归因于首步数值噪声；没有追加第三种补偿计数的变体。

预登记的描述性机制门槛：

1. 每组3次运行形成3个组内比较对；各取RGB逐通道绝对差均值、深度绝对差均值的组内中位数。候选／原策略两项比值都必须≤0.8，即都降低至少20%。
2. 比较3次运行平均的训练观测拟合。完整作者目标、RGB L1、深度L1三个候选／原策略比值都必须≤1.05。
3. 工程完整性与机制门槛分开判定；门槛未满足即保留负结果，不放宽、不补跑筛选有利重复。

完整作者目标按固定支持像素数N归一化：

\[
L/N=[w_g\sum_M|D-D_o|+w_c(1-\lambda)\sum_M\|C-C_o\|_1+\lambda(1-\mathrm{SSIM}(C,C_o))]/N.
\]

SSIM使用完整图像，与作者一致。它针对训练观测，其中深度是DROID估计；这个拟合量不是独立几何真值质量。

## 4. 实测结果

所有运行的输入、完整RNG、初始地图六参数、首次前向与首次pre参数均逐位相同。原策略首步rotation角中位数为0.052809～0.053304°，单高斯最大约0.197605°，与T04解析估计量级一致。候选3次首步rotation参数变化均严格为0，Adam状态未分配，其他五组step均为1。候选第1轮正常建立rotation状态并更新；第一段结束其rotation step为499，原策略为500。三个候选共跳过3次旋转组更新，其余Adam调用保持原流程。

首步scaling更新后已有各向异性：三轴log尺度极差最大0.00020027。第1轮rotation梯度L2约0.0472～0.0474，显著大于第0轮的约1.84e-5～2.48e-5。因此不能由初始旋转不可观测，直接推导长期冻结旋转合理。

## 7. 下一步：T3-DG-T06高斯地图支持质量与tracking受控验证

不继续根据这个负结果直接扩展旋转冻结阈值。回到研究主问题：高斯地图提供的哪些观测约束真正帮助相机精修，哪些覆盖看似充分却会错误牵引相机。

T06建议复用T03已冻结的47／95帧地图与观测，固定地图、相机初值与优化预算，先在CPU整理高斯尺度／协方差、投影支持的空间分布、深度一致性与现有tracking筛选逻辑，区分作者已有机制和待测新因素。随后再登记基于高斯支持质量的单因素候选，以及固定相机扰动下的恢复／退化检查。不能只凭训练loss下降或opacity高就判定精修可靠。

T06的候选定义、阈值与GPU预算须在实验前固定；本轮未执行T06，不自动采用回退策略、不直接扩828帧。CPU准备不需要GPU，受控render／位姿优化需要GPU。正式tracking／mapping收益仍按原多窗口多种子门槛验收。
