# T3-DG-T07：高斯分散度混合权重与相机恢复消融

日期：2026-10-11。研究主线：利用3D高斯的表示与渲染特性改善tracking／mapping。

## 1. 结果与决定

**T07完成，工程完整性PASS，预登记DEV机制门槛NOT_MET，候选不采用。** 两张冻结地图、六轴正负扰动、零扰动检查及真实观测检查，共168次相机优化、8400次backward／Adam step，所有预算执行完毕。

固定50%混合权重解决了T06的有效加权样本量不足：准备案例中最低ESS/N为70.76%，高于50%门槛。但在已知参考位姿的自渲染恢复中，候选归一化位姿误差比均匀权重**高23.74%**；两帧分别高25.33%与22.04%，成功率都未提高。真实观测下共同残差变化较小，不能据此认定相机位姿更准确。

因此，本轮不继续调整混合比例或5cm尺度。保留“高斯深度分散度与观测不一致相关”的T06发现，同时记录：这种相关性没有在当前固定预算的相机恢复中转为收益。下步优先研究高斯渲染对位姿方向的约束及优化条件，而非继续把高分散度统一解释为应该降权。

这里的UNIFORM也是**受控固定支持参考组**；它不是作者原动态mask的完整tracking系统。结果不是完整轨迹ATE，更不能写成DG-SLAM精度退化23.74%。

## 2. 唯一候选与实验直觉

T06的直接权重使有效约束集中到少量像素。T07保留一半均匀基础权重，只用另一半表达高斯中心深度分散度：

\[
q_p^*=\frac1{1+(\sigma_{z,p}/0.05\mathrm m)^2},\quad
q_p=\frac{q_p^*}{\operatorname{mean}_{M}(q^*)},\quad
w_p^{mix}=0.5+0.5q_p.
\]

UNIFORM取w=1；MIX50取上述混合。权重均值为1，MIX50下界为0.5。没有硬删支持像素、没有学习权重、没有搜索混合比例或尺度。

对于T06的固定支持L2敏感度代理，有\(H(w^{mix})=0.5H(1)+0.5H(q)\succeq0.5H(1)\)。这个代数下界保证的是代理矩阵，不保证作者L1目标下的Adam收敛或精度；本轮实际结果说明二者需要区分。

权重从每个案例**实际扰动后的初始位姿**提取高斯alpha合成深度矩，然后冻结。扰动案例没有使用恢复目标位姿来构造权重。原生深度继续为\(D=\sum\alpha Tz\)，不除以A；σz是贡献高斯中心间分散度，不是校准位姿不确定性。

## 5. 自渲染位姿恢复结果

\[
