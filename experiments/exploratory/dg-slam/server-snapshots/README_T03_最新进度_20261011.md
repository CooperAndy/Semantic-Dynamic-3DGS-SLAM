# T3-DG-T03：固定地图相机优化重复性验证

日期：2026-10-11。研究方向：利用3D高斯的表示、渲染和地图维护改善tracking／mapping。本文为定位实验，不是新方法收益验收。

## 1. 本轮结论

**T03执行与回放完整性通过；严格数值重复性未全部通过，逐位重复性不成立。** 两个固定输入案例、两种观察模式、每种3次独立进程，共12次实际作者50轮相机优化，600轮优化、624次渲染，无DROID推理、建图或轨迹补全。

12次初始RGB、深度、透明度、掩码与首轮损失，均与T02保存值完全一致。DIAG重复之间的首次前向计算及相机参数相同，**首次反向传播的四元数叶梯度已不同**；平移叶梯度在6对比较中5对不同。首轮Adam后的参数仍逐位一致，后续才产生参数／loss分岔。因此“固定种子就保证这条自定义CUDA梯度路径逐位确定”的假设不成立。

全部30个比较对中，预登记的联合标准通过11对；原阈值下单看最终位姿通过29对。最大最终平移差为 **0.0117475毫米**，最大旋转差为 **4.91089e-6弧度（约0.0002814°）**，最大逐轮loss相对差为 **0.0233134%**。数值差很小，但不能在看到结果后放宽阈值并改判通过。

本实验把观察到的最早分岔缩小到固定输入的反向传播路径；没有证明具体哪一个kernel造成分岔，也没有证明这些微差足以解释T02两次整条轨迹ATE相差32.53%。**下一步T04优先检查首次mapping输入与建图阶段的可重复性。** 当前不更改高斯同步、不更改候选时序、不采用残差回退策略、不扩大到828帧。

## 3. 两种模式与预登记标准

| 模式 | 共同记录 | 额外操作 | 每次渲染 |
|---|---|---|---:|
| BASE | 每轮pre-camera、post-Adam叶参数、作者返回loss，首次RGB／depth／acc／mask | 无额外渲染或梯度hook | 50 |
| DIAG | 同BASE | 使用T02同哈希Observer；另记录完整四元数／平移梯度；优化后4次缓存／live重渲染、哈希和快照 | 54 |

BASE有共同trace记录，因此不是完全无观察的计时基线。DIAG增加了完整梯度hook，不能将所有差异单独归因于T02 Observer中的某个操作。两种模式都不接受／拒绝候选，也不替换作者输出。

预登记数值阈值同时要求：逐轮loss最大相对差≤1e-5；最终矩阵最大元素差≤1e-5；最终平移差≤1e-5m；最终旋转差≤1e-4rad。初始RGB／深度／acc最大绝对差≤1e-5，初始掩码必须完全相同。逐位相等另行报告。

每个案例有3对BASE内部重复、3对DIAG内部重复，以及BASE×DIAG的9对交叉比较。共30对，**共享同一组12次运行，不是30个独立实验样本**。联合通过率是诊断统计，不是泛化概率。

唯一超出位姿数值阈值的比较为第95帧BASE r1对DIAG r3：平移差1.17475e-5m、矩阵差1.15680e-5。所有旋转差都在登记阈值内。29／30的“单看位姿通过”和11／30的“联合通过”仅拆分解释原判据，没有更换阈值。

首次反向传播，DIAG重复之间四元数梯度的相对L2差为1.02137e-7～4.41947e-7；平移梯度为0～4.97849e-7。300轮DIAG优化的两组叶梯度均有限且非零。完整梯度、逐轮损失和pre／post参数保存在各运行`trace.npz`。

作者depth_pose光栅器`cuda_rasterizer/backward.cu`在颜色、深度、投影均值、conic及透明度梯度中使用浮点`atomicAdd`。这是反向数值微差的合理候选来源；**当前只是源码支持的推断，没有替换kernel或改变归约顺序的因果实验**。有限、非零梯度也不等于导数已通过正确性验证。
