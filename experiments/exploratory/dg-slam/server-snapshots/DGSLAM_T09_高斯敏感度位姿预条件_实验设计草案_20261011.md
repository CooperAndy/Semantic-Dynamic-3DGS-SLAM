## 1. 要回答的问题

保留高斯像素约束，利用实际地图渲染对六自由度的敏感度，能否在固定预算内改善位姿恢复？收益究竟来自换参数化、逐轴调整尺度，还是处理平移—旋转耦合？

T08提示两帧存在强耦合，也显示高分散度像素承载弱方向约束。下一轮保持均匀像素权重，不继续MIX50比例／尺度搜索。

## 2. 四组对照

| 组 | 相机参数化 | 敏感度变换 | 用途 |
|---|---|---|---|
| Q_AUTHOR | 原wxyz四元数＋世界平移 | 无 | 作者参数化受控参考 |
| SE3_ID | 局部SE(3)指数坐标 | I | 隔离更换参数化的影响 |
| SE3_DIAG | 与SE3_ID相同 | 只取H对角的阻尼逆平方根 | 隔离逐轴尺度调整 |
| SE3_FULL | 与SE3_ID相同 | H完整阻尼逆平方根 | 检验耦合结构的增量价值 |

前三个SE(3)组的共同表达为`T(u)=T_init Exp_SE3(S P u)`；S固定2cm／1°。P在初值处建立后冻结，不在每轮变化。ID取I；其余以`Hbar=H/(trace(H)/6)`、固定阻尼0.01构造P，使用同一Frobenius范数归一化规则，避免额外自由的整体增益。**具体共同学习率、归一化实现、精度和自动微分检查必须在正式GPU运行前锁定，不依据结果选择。**

H使用原生高斯渲染器，在每个**实际相机初值**进行六轴中心有限差分；仅用该初值的共同支持计算。不能复用在自渲染答案位姿处计算的T08矩阵作为扰动试验的候选输入。目标参考只用于自渲染观测和事后数值评分，不参与P构造。

- 预计28案例×4组×3重复＝336次优化、16,800轮；每次最终共同重评分。初值Jacobian构建预计26个不同初值×13次render＝338次额外前向。它们与优化轮数分报，不宣称预条件无额外成本；正式计数以登记协议和实际回执为准。
- 先通过CPU坐标／SE(3)微分测试，再做GPU实现完整性检查；任何初始化或自动微分失败都应停止，保留现场，不拿异常结果评价方法。

## 4. 建议锁定的DEV验收与停止规则

主要指标沿用T07的归一化恢复误差E；先对每帧／轴／符号／组的3次重复取中位数，再按24个非零扰动案例平均。自渲染零扰动与真实观测另报。

| 条件 | 建议门槛 |
|---|---|
| FULL相对ID、DIAG总体E | 分别至少降低10% |
| FULL相对Q_AUTHOR总体E | 至少降低10%，避免只改善较差的新参数化基线 |
| 每帧E | 相对每个对应基线不得退化超过5% |

| 零扰动漂移 | 平移≤1e-5m，旋转≤1e-4rad |
| 真实观测共同RGB／depth拟合 | 相对参考不得退化超过5% |
| 真实观测覆盖 | 不降低超过2个百分点 |
| 工程 | 配对输入、有限梯度、实际50轮、候选时间、地图／源码／native哈希全部通过 |
