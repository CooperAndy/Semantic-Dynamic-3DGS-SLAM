# T3-DG-T08：高斯位姿方向约束与优化条件——CPU分析

日期：2026-10-11。研究主线：利用3D高斯的表示与渲染特性改善tracking／mapping。

## 1. 结论与决定

**T08的CPU分析完成，工程完整性PASS；新算法恢复效果尚未评价，未采用新方法。** 本轮复用T06／T07档案，没有新GPU渲染、backward、相机优化、建图写入或GT读取。

相机向侧面移动与小幅转动，都可能把同一片高斯投到相似的图像位置。优化器可以迅速消除易区分的误差，却在这些相互补偿的方向上进展缓慢。本次两帧的实际高斯渲染敏感度都显示了这种现象：最强平移—旋转耦合相关度为0.9869／0.9843；去除各轴幅度差之后，条件数仍为205.36／177.04。

另一个关键发现是：**高深度分散度不等于没有位姿信息。** 分散度最高的四分之一像素，为两个最弱方向提供了49.22%／44.41%的敏感度。它们虽然与较大的DROID深度残差相关，却可能也是弱方向的重要约束来源。这与T07降权未取得恢复收益相容，但不是T07失败的因果证明。

下一轮值得验证“保留像素约束，调整六自由度更新的方向与尺度”。先做受控位姿恢复，区分参数化、逐轴尺度调整和完整耦合预条件；不继续混合比例调参，不直接扩完整序列。高斯地图相关的预条件器仍只是候选。

## 3. 统一坐标后再比较

六维顺序为`tx, ty, tz, rx, ry, rz`，平移以2cm、旋转以1°缩放。T06对局部相机右扰动做中心有限差分：平移步长1mm、旋转步长0.01°。

令缩放后的RGB／原生深度导数为Jc、Jd，在固定支持M上：

\[
H=\frac1{|M|}\sum_{p\in M}\left(0.9J_{c,p}^{\mathsf T}J_{c,p}+0.1J_{d,p}^{\mathsf T}J_{d,p}\right).
\]

这是实际高斯渲染器的**有限差分L2敏感度代理**，不是作者L1目标的Hessian、Fisher信息或校准位姿不确定性。原生深度仍为未除以透明度总和的D；没有改变深度定义。

T07保存的是原始wxyz四元数与世界平移梯度。设四元数q=(w,v)，局部小旋转到原始四元数的导数为：

\[
B(q)=\tfrac12\begin{bmatrix}-v^{\mathsf T}\\wI+[v]_\times\end{bmatrix},\quad
g_{local}=\begin{bmatrix}R^{\mathsf T}g_t\\B(q)^{\mathsf T}g_q\end{bmatrix}.
\]

再乘各轴物理尺度，才得到可与缩放位姿步长比较的梯度。实际步长用更新前相机坐标中的平移差与`log(R_preᵀR_post)`表示；它是局部一阶坐标，不把该拼接向量称为完整SE(3)对数。

## 4. 高斯渲染的弱方向与耦合

| 指标 | 帧47 | 帧95 |
|---|---:|---:|
| 真实固定支持像素 | 90,881 | 84,859 |
| H最大／最小特征值之比 | 469.83 | 363.91 |
| 对角归一化后的条件数 | 205.36 | 177.04 |
| 最大平移—旋转典型相关度 | 0.98693 | 0.98434 |
| 第二大典型相关度 | 0.96432 | 0.95411 |
| 允许旋转补偿后的最小平移约束保留比例 | 2.60% | 3.11% |
| 最弱／次弱方向的平移分量平方占比 | 90.34%／84.94% | 90.29%／88.60% |
| RGB对H迹的占比 | 86.47% | 92.81% |

“保留比例”来自平移块的Schur补：把可由旋转解释的响应消去后，与原平移块做白化比较。矩阵仍为正定；弱方向不等于完全不可观测。典型相关度、特征向量和保留比例都依赖本轮缩放、支持和L2代理，不能直接解释成真实相机置信区间。

对角归一化后仍然很差，提示仅调整平移／旋转学习率可能不足以处理耦合。它不证明某个完整矩阵预条件器一定有效，也不证明这是3DGS独有问题。

## 5. 高分散度像素也提供弱方向约束

按同一支持上的高斯中心深度分散度等数量分四组；下面是最高四分位Q4：

| Q4指标 | 帧47 | 帧95 |
|---|---:|---:|
| 像素占比 | 约25% | 约25% |
| DROID深度残差均值 | 1.00455m | 0.71459m |
| 全方向敏感度迹占比 | 26.33% | 20.73% |
| 两个最弱方向的敏感度占比 | **49.22%** | **44.41%** |

弱方向占比计算为`trace(V_weakᵀ H_Q4 V_weak) / sum(lambda_weak)`。它表示该组像素对固定代理方向的响应平方贡献；不是像素准确率或真实信息量估计。

将T06同参考位姿的直接权重与均匀权重各混合50%，代理条件数变为582.27／449.79，比均匀组更差。这个计算使用T06原参考权重；T07实际权重是在每个扰动初值重新构造，二者不能混称同一数值实验。

## 7. CPU参考预条件与验收

固定代数参考：`Hbar=H/(trace(H)/6)`，`P=(Hbar+0.01I)^(-1/2)`。矩阵P作为坐标变换时，代理变为`Pᵀ Hbar P`；两帧条件数为2.073／1.876。这个改善是对已知正定矩阵进行白化的代数结果，**不是新相机恢复收益**。不能直接把一次`P*g`操作等同于这一坐标变换。

CPU实现了含小角度分支的完整SE(3)指数映射，检查了零／小／一般扰动、旋转正交性和逆变换。新GPU实现仍需另行核对其自动微分与零点数值稳定性。
