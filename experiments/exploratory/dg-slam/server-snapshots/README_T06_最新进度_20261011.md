# T3-DG-T06：高斯支持质量与位姿敏感度验证

日期：2026-10-11。方向：利用3D高斯的表示与可微渲染特性改善tracking／mapping。

## 1. 结果与研究决定

**T06已完成：工程完整性PASS，当前直接降权候选资格NOT_MET，不采用。** 完成两帧冻结地图的CPU核对，以及预登记的28次GPU前向渲染；没有backward、Adam更新、建图写入或完整轨迹运行。

发现一个与高斯表示直接相关、值得保留的信号：同一像素参与alpha合成的高斯中心深度越分散，与DROID观测深度的残差通常越大。47／95帧的Spearman相关系数分别为0.635／0.565，最高分散度四分位的平均深度残差约为最低四分位的15.93／15.59倍。

但不能直接把所有高分散度区域强烈降权。预登记权重使有效加权样本量仅相当于原支持的42.77%／46.33%，没有达到每帧至少50%的门槛；最弱位姿敏感方向也被削弱，信息代理矩阵条件数约增大到原来的1.87／1.88倍。因此保留高斯分散度信号，停止采用本轮强降权形式，不修改阈值补判。

以上是两张已观察DEV地图上的诊断，**尚未证明tracking精度改善**。深度来自DROID，相关性不是几何真值评价；分散度与深度残差共用渲染一阶矩，不能把相关性当作独立预测验证。

另核对到原生深度为未归一化的alpha合成量：

\[
D=\sum_i \alpha_iT_i z_i,\qquad A=\sum_i\alpha_iT_i.
\]

原生输出没有除以A。这是本次核实的实现约定，不直接判为bug；本轮没有修改它。CPU另算D/A只作描述：深度残差中位数在帧47从9.2267降为9.0469cm，在帧95从5.4933变为5.5045cm，并没有一致改善。之后的残差与位姿Jacobian继续使用作者原D，避免同时改变深度定义。

## 3. 预登记GPU验证与矩计算

协议在任何T06 GPU调用前登记，SHA256：`dac002ec5537d233779ba8e5b619e7f25264d03f7597e48ea40aeebd8192223a`。

现有渲染入口支持`override_color`，可以给每个高斯赋三通道`(z,z²,1)`。黑背景下，实际光栅器返回：

\[
m_1=\sum_iw_iz_i,\quad m_2=\sum_iw_iz_i^2,\quad A=\sum_iw_i,\quad w_i=\alpha_iT_i.
\]

然后计算条件均值与高斯中心深度分散度：

\[
\mu=m_1/A,\qquad\sigma_z=\sqrt{\max(m_2/A-\mu^2,0)}.
\]

它测量的是实际参与像素合成的不同高斯**中心深度**分散，不包含单个高斯沿射线的条件方差，也不是校准的位姿不确定性。

## 4. 位姿敏感度与候选资格

六轴中心差分步长：平移±1mm，旋转±0.01°；沿粗c2w的局部相机轴右乘。为了比较不同量纲，Jacobian平移列乘2cm，旋转列乘1°对应的弧度。

固定原支持M，构造六维L2敏感度代理：

\[
H(q)=\frac1N\left[0.9\sum_{p\in M}q_pJ_{C,p}^TJ_{C,p}+0.1\sum_{p\in M}q_pJ_{D,p}^TJ_{D,p}\right].
\]

它不是作者L1目标的精确Hessian，也不是经过噪声校准的Fisher信息或位姿协方差。可见性边界与浮点噪声会进入有限差分，本轮没有声称已经排除这些影响。

唯一候选预先固定为：

\[
q_p^*=\frac1{1+(\sigma_{z,p}/0.05\mathrm m)^2},\qquad q_p=q_p^*/\operatorname{mean}_{M}(q^*).
\]

权重在原粗位姿冻结，均值归一为1；没有额外硬删像素、没有调5cm尺度。有效加权样本量比例为\((\sum q)^2/(N\sum q^2)\)，**不是实际保留像素比例**；原90881／84859个支持像素均参与分析。
