# T3-DG-T04：首次建图输入与分阶段重复性定位

日期：2026-10-11。方向：利用3D高斯的特性改善tracking／mapping。本文记录定位实验；没有评估新方法的ATE或几何真值收益。

## 1. 结论与下一步

**T04已完成，工程完整性PASS，首次建图的严格重复性NOT_ESTABLISHED。** 已区分两类变化：

1. **进入高斯建图之前，DROID深度已经不同。** 3次相同种子、同输入顺序的独立前端捕获中，RGB、seg、粗位姿、投影、动态半径、随机状态和空地图状态完全相同，只有DROID深度不同。共同有效语义支持区的深度差中位数约0.28～0.29毫米，99分位约1.25～2.58厘米；局部最大0.65米。
2. **把输入与随机状态彻底固定后，建图仍会分岔。** 6次回放初始12185个高斯的六类参数完全相同；3次详细记录中的最早差异均在第0轮反向梯度。第一段500轮优化之后位置已有差异，接着第二段视锥选择不同，最终保留12159～12161个高斯。15个比较对均未通过登记标准。

这次还发现了与高斯表示直接相关的候选问题：**所有初始高斯都是各向同性，此时旋转不改变协方差，却仍得到微小、不稳定的旋转梯度。** 根据保存梯度作Adam首步解析估算，中位旋转更新约0.053°。它值得做独立干预验证，但目前没有证明它是分岔的唯一或主要原因。

下一步建议 **T3-DG-T05：只禁用“全部高斯仍各向同性”的首轮旋转更新，做最小机制消融**。先检验该表示退化处的更新是否放大噪声，再决定是否扩展为按各向异性控制旋转更新。T05尚未执行；没有采用新策略，没有更改作者源码或正式质量门槛。

共同支持要求两份深度都在(0,8)m且原seg为真。全图还包含作者不用于当前深度损失的远距离／异常值，因此不能用全图最大差代替有效区域统计。这里的深度是DROID估计，不能称为传感器真值。

作者首轮采样预算依赖深度中位数，再取整数：

\[
n=2\left\lfloor\operatorname{clamp}\left(10000(d_{median}/2.5)^2,10000,30000\right)\right\rfloor.
\]

事后CPU按float32计算，3份输入得到25980／25984／25986个raw样本预算；第1份与实际DIAG采样25980完全相符。**第2／3份的数值是公式估算，没有实际运行其mapping或随机采样。** 在第1份的同一组采样坐标上，3份深度都保留12185个有效样本；因此不能把完整图11～22个支持差像素直接说成本次初始点数差的原因。

这给出两个待区分的离散放大环节：深度中位数改变整数采样预算，以及局部深度跨过8m有效阈值。DROID内部哪一步造成入口深度差尚未定位；本轮未证明它们各自对完整SLAM误差的贡献。

## 7. 高斯各向同性与旋转可观测性

所有12185个初始高斯均有完全相同的三个尺度，四元数都是单位旋转。若尺度为s，则

\[
\Sigma=R(s^2I)R^T=s^2I.
\]

此时旋转不改变协方差，几何形状不能提供旋转证据。这是高斯表示本身的退化，不依赖动态类别或语义先验。

实际第0轮rotation梯度L2为1.73e-5～2.43e-5，最大绝对分量约0.97e-5～1.39e-5；三个虚部均出现很小的非零梯度，而且跨重复有大量符号差异。其他非零参数组首轮梯度的相对L2差约8.1e-7～4.1e-6，rotation的相对差因基准接近零而不能直接作为“梯度很大”的证据。

新Adam、lr=0.001、eps=1e-8时，首步解析形式为`Δq≈-lr*g/(|g|+eps)`。用实际保存梯度在CPU估算，归一化后的旋转角更新中位数约0.0523～0.0530°，最大约0.1978°。**这是解析估算，不是捕获的实际post-step数组。** 微小梯度可能经自适应归一化成为非零旋转更新，是一个值得干预的假设。

尚未执行旋转梯度／优化器干预，不能认定它解释了全部建图分岔，更不能据此宣称tracking改善。该候选机制也尚未完成与已有工作的创新性比较。
