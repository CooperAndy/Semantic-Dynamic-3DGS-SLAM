## 2. 验收与逐帧审计

每个关键帧记录实际RGB对应的input_frame_id、DROID粗c2w、tracking后c2w、mapping后c2w、50次优化前向损失、精修耗时和地图点数。loss在Adam更新前计算；后续T02实测确认，当前`separate_LR=True`的拼接camera值仍为pre-step值，保存候选确实对应这次评分，不能仅凭保存语句在step之后就认定错位。

工程验收要求：两组完整输出200条有限位姿；关键帧实际RGB身份与时间戳对应；GT无输入／缓存／读取；OFF相机优化次数为0，ON为`50×(关键帧数−2)`；位姿矩阵刚体检查与DROID四元数往返通过。另核对关键帧ID及精修入口的DROID粗位姿是否配对，最大矩阵元素差容许`1e-4`，超过则标记混杂，不能直接归因。

分别评分三类结果：所有200帧经作者DROID补全后的轨迹、未补全的高斯关键帧、同一粗位姿对齐坐标下的精修前后误差。稀疏关键帧RPE的delta=1表示相邻关键帧，不等于输入序列相邻帧。

### 3.1 已有诊断指向什么

在22个可精修关键帧中，21帧的最小观测优化loss低于首轮，下降中位数2.36%，但在固定粗位姿对齐下只有6帧位置误差改善。第47输入帧的误差从0.749cm升至3.073cm；56、95、40、82帧也出现明显增加。精修平移量中位数0.986cm、最大5.481cm，旋转修正中位数0.207°、最大1.221°。

这些事实说明**loss变小尚不足以保证位姿更准**。T01没有记录共同支持集上的分量残差；候选时间的疑点已由T02排除。不能认定退化就是由某一掩码或深度错误造成，也不能按GT挑帧接受精修。

作者轨迹补全确实改变了关键帧：OFF最大平移改变1.284cm，ON最大改变1.975cm；ON旋转最大改变0.393°。因此“稀疏关键帧ATE略好、全帧ATE略差”必须分别保留，不能选择其中一个指标代替整体结论。

ON的新跑ATE为1.6859cm，旧R1.1为1.7505cm，同种子运行也没有位级复现。粗输入配对检查通过，但小幅收益仍需重复运行确认，不能据本次1.95%的稀疏改善建立研究结论。

### 3.2 结论与下一任务

本次配对管线验收通过；**没有得到ATE与RPE一致改善的证据，不采用原样50轮高斯精修作为已验证改进**。全轨迹ATE增加4.90%，尚未超过本次5%的ATE退化标记，但未达到降低10%的正式门槛；旋转RPE变差也必须保留。单窗口单种子不足以执行正式采用判定。
