## 验证边界

1. 先确认环境和数据复用条件，再安装独立环境和运行GPU实验；已有环境不直接升级、降级。
2. 第一轮优先使用官方支持的 TUM RGB-D 动态序列。已有 KITTI/VKITTI 不自动等价于作者配置的输入；Replica 静态数据只能作为另行适配的工程检查。
3. 冒烟窗口暂定连续30帧，超过原入口12帧warmup；仅证明工程链能够运行。随后再固定连续100–200帧小窗口，检查轨迹和地图，不以短窗口结果声称复现论文全序列成绩。
4. 完整方法使用预测语义掩码；零掩码或现有其他模型的掩码必须标为诊断/替代输入，不能冒充官方OneFormer配置。标签编码、缩放和膨胀规则需要核验。
5. 作者代码中的GT初始化和尺度对齐设置需要分别记录。估计轨迹、GT轨迹分开保存；原作者设置与后续无GT辅助设置不得混报。
6. 定位和建图评价与阶段3语义mIoU评价分别解释；删除动态区域不自动构成语义质量提升。
