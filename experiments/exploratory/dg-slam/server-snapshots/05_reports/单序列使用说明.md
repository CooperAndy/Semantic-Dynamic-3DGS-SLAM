# TUM walking_xyz 单序列准备

本次仅下载论文官方脚本包含的 **一条完整序列**，没有下载整套TUM或BONN，不启动GPU、不运行分割或SLAM。实际安装核验结果见同目录 `dataset_receipt.json` 与 `单序列安装核验结果.md`。

## 服务器位置

```text
/root/autodl-tmp/dg_slam_chy_20261011/02_data_masks/
├── archives/rgbd_dataset_freiburg3_walking_xyz.tgz
├── TUM/rgbd_dataset_freiburg3_walking_xyz/
│   ├── rgb/
│   ├── depth/

├── dataset_file_hashes.json

├── official_loader_selected.csv
├── smoke_first30.csv

```

原始文件保持原名和单位；原始深度PNG的数值除以5000得到米，不提前改写深度。GT仅作为对应核验和后续独立轨迹评价的来源，不能把运行输出的估计位姿写成GT。

## 已核对的作者入口

官方版本：`fb28a20caa74f376ebd4a5f3c473cd57e7f5d9b4`。

实际配置：`configs/TUM_RGBD/rgbd_dataset_freiburg3_walking_xyz.yaml`。

在该版本 `data/tum_split.txt` 中，该序列位于第二项，因此命令行索引为 **`--id 1`**。入口会据此覆盖 `--config`；不依赖入口默认的 `fr3_walk_xyz.yaml` 名称。

以后完整源码、兼容环境、DROID权重及预测掩码都准备好后，在独立源码目录运行的单序列命令形式为：

```bash
python run_tum.py \
  --datapath /root/autodl-tmp/dg_slam_chy_20261011/02_data_masks/TUM \
  --id 1 \
  --disable_vis
```

**这不是当前已可执行的验收命令**：本次只准备数据，尚未完成上述代码和模型安装。没有 `--id 1` 会遍历作者的多序列列表。输出目录需要在以后独立源码副本的配置中指定，不能写入旧阶段3。

## 为后续小规模检查保留的索引

关联使用作者入口的RGB→最近深度、RGB→最近GT规则，时间差均需小于0.08秒；再按作者 `frame_rate=32` 规则选帧。

- `official_loader_selected.csv`：完整序列中作者入口将选择的有效帧。
- `smoke_first30.csv`：上述列表的前30帧，用于后续短序列工程检查。
- `dev_first200.csv`：上述列表的前200帧，用于之后固定的小规模诊断。

CSV仅保存索引，不复制图像。作者入口本身没有根据这些CSV截取窗口的功能，后续需在独立副本增加明确的窗口参数；本次没有运行或声称已完成这些窗口实验。
