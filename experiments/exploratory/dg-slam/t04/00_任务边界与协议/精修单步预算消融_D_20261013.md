# T04：精修单步预算消融（D 阶梯）预登记

登记日期：2026-10-13。归属：CHY 独立 KITTI00 0–199 主线。状态：**PREPARED_NOT_RUN**。

前置：[精修目标函数修复结果](../05_报告与归档/精修目标函数修复_20261013/结果与结论_20261013.md)。

## 一、为什么做这一组

C 臂登记的单步预算为 5 mm / 0.05°。收尾统计显示该预算**触发 1,954 次、占全部 2,600 次精修迭代的 75.2%**，而最小覆盖率保护触发 0 次。也就是说：

- 单步钳制不是安全网，而是 C 臂的**主要作用机制**；
- 这个预算值本身**从未被验证**，很可能过紧——过紧会限制收敛，使精修无法产生正收益。

因此必须把"冻结支持集"与"限制单步位移"的贡献拆开。本组只改预算，其余全部冻结。

## 二、阶梯设计

| 档位 | 平移预算 | 旋转预算 | 说明 |
|---|---:|---:|---|
| D-tight | 1 mm | 0.01° | 本轮新增 |
| **D-reg** | **5 mm** | **0.05°** | **= 已完成的 C 臂，直接复用，不重跑** |
| D-loose | 20 mm | 0.2° | 本轮新增 |
| D-nocap | 关闭 | 关闭 | 本轮新增；只剩"冻结支持集"在起作用 |

D-nocap 是这组里最有信息量的一档：它与 B_on 的区别**只有冻结支持集**，因此能直接回答"光靠冻结能不能救回精修"。

## 六、预登记的判读规则

**只看 RPE1 与 RPE10 平移，明确不以 ATE 判定。**

1. 最优档是 D-reg ⇒ `CAP_INTERIOR_OPTIMUM`：登记预算接近合适值。
2. 最优档是 D-tight ⇒ `CAP_STILL_TOO_LOOSE`：还需要更紧。
3. 最优档是 D-loose 或 D-nocap ⇒ `CAP_HURTS`：预算在限制收益，**冻结支持集才是有效修复**，后续应取消或大幅放宽钳制，转而去改优化目标本身。

另需报告：最优档是否追平 off 地板（RPE1 ≤ 0.041864 且 RPE10 ≤ 0.312666）；若追平或更好，说明精修第一次成为非负收益。
