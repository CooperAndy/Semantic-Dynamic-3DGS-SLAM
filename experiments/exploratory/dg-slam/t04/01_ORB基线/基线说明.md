# 已冻结的历史ORB基线

选用KITTI odometry seq00第0–199帧，共200帧；输入为P2/P3彩色校正双目，1241×376。这是独立只运行200帧的轨迹，未截取完整4541帧运行的优化结果。

| 项目 | 结果与来源 |
|---|---|
| 轨迹 | 原始输出/CameraTrajectory.txt，200行KITTI 12列c2w、P2相机 |
| 关键帧 | 原始输出/KeyFrameTrajectory.txt，65行 |
| 历史ATE RMSE | 0.488110 m，P2→P0、SE(3)对齐、无尺度校正 |
| 历史1帧平移RPE RMSE | 0.033239 m，相邻199对 |
| 本轮独立CPU复算ATE | 0.4881095492527189 m，与历史六位小数一致 |
| 本轮独立CPU复算1帧RPE | 0.03323918262762652 m，与历史六位小数一致 |
| 本轮补充10帧RPE | 0.22630906258167946 m，190对；新补充指标，不冒充历史报告值 |
| 历史平均／中位tracking时间 | 0.0260077／0.0248892 s |
| 历史退出码 | 0 |

CPU核验检查了原始轨迹与P2导出一致、200行有限值、旋转正交误差、calib计算的P2→P0转换与历史评价轨迹一致、GT前200行与本地完整GT一致，以及ATE／RPE复算。[结构化回执](独立CPU核验.json)。这不是重跑ORB，也不是逐帧在线轨迹记录：保存的轨迹可能含本200帧窗口内的地图优化，但不含第200帧之后的输入。

内参fx=fy=718.856、cx=607.1928、cy=185.2157；bf=382.66995 px，历史报告水平基线约0.532332 m。P2→P0通过calib投影矩阵求解外参，不手工再对c2w求逆。

`历史评价/seq00_gt_kitti_200.txt`和P0转换轨迹仅供独立评价。Gaussian跟踪不允许读取GT位姿，也不能读取ORB轨迹作为初始化后再宣称自主tracking。固定位姿mapping可另立实验，明确其角色。

历史运行平台是Windows／WSL。历史tracking均值不能直接与3080 Ti服务器Gaussian worker总耗时比较；公平成本对照需同机器新跑ORB，分别计入初始化、逐帧跟踪、终止优化和额外深度／语义推理。

归档中历史验收报告包含4541帧背景，主对照只认上述独立200帧。未将全序列轨迹或其前200帧后验优化结果作为主基线。
