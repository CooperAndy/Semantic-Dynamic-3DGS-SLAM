# Gaussian适配KITTI seq00前200帧：缺口与下一步

日期：2026-10-12。只读核对本地官方参考和服务器当前源码快照，未修改远程文件、未执行GPU。服务器当时3080 Ti空闲，数据盘约15 GB可用；资源快照不保证后续状态。

## 判断

**现有DG-SLAM不能只改路径直接跑这段KITTI。**服务器保存版本的根目录只有`run_tum.py`，配置只有`TUM_RGBD`与通用配置；尝试读取`run_kitti.py`返回不存在。这个结论限本次保存版本，不泛指其他分支或上游未来版本。

R1.1的`dg_model.track(tstamp,image,depth,intrinsics,seg_mask)`已去掉GT位姿参数，首张高斯地图使用Identity，可以作为后续隔离适配的候选。通用`scripts/run_window.py`与`tum_window.py`仍是旧TUM准备入口，其中会读取GT，不能误把这些脚本当R1.1的无GT运行器直接套用。必须另核对R1.1实际worker／运行manifest并在KITTI独立入口接入无GT接口。

## 已确认的具体缺口

| 项目 | 源码／数据事实 | 需要完成 |
|---|---|---|
| 数据入口 | TUM读取rgb/depth/GT关联与32Hz筛选；KITTI是同步双目、10Hz左右 | 新KITTI加载器严格使用000000–000199与times前200行，索引不含GT／ORB位姿 |
| 尺寸与K | TUM写死512×384和0.8×K；mapper还写死scale_factor=0.8 | 统一一次缩放／裁剪的定义，独立sx/sy和裁剪偏移传播到各模块；防止双重缩放和视野拉伸；检查网络步长8约束 |
| 传感器模式 | 旧runner设置stereo=False；DepthVideo有stereo分支 | 有分支不等于原生KITTI可用；审计右相机特征、基线／单位、投影／BA和终止补全链，不能只打开--stereo |
| 深度 | TUM输入PNG除以5000；本地已有SGBM的米制候选npy，但尚未核验生成身份 | 核验深度单位、零值／NaN、视差与bf、左右对齐、缓存来源和未来帧依赖；不能对npy继续除5000 |
| 高斯实际深度 | dg_model将DROID上采样逆视差反演后交给高斯 | 分开记录输入双目派生深度、DROID深度和渲染深度，不把任何一个叫几何GT |
| 室外尺度 | mapper中scale_factor=0.8，多处gt_depth<8米硬编码 | 将tracking／mapping各深度筛选和尺度相关阈值列出并预先固定室外配置；不能只改一个配置键或看ATE调范围 |
| mask | TUM入口按ADE20K类别12做人形筛选、膨胀和缩放 | 决定保留固定预测person-mask还是另立明确的无语义诊断变体；禁止假空mask冒充预测，也不默认恢复dynamic调参 |
| 坐标 | KITTI图像来自P2；公共GT是P0；DROID和高斯还涉及xyzw/wxyz、c2w/w2c | 投影、轴方向、米制平移与四元数往返自检；评价才做P2→P0，不用GT校准运行尺度 |
| GPU与收尾 | 30输入帧此前不足12关键帧warmup；200帧数量不保证关键帧覆盖 | 冒烟按实际关键帧／GS调用验收，不降低warmup伪造通过；检查200帧终止、地图精修和保存是否真实触发 |

上表源码证据保存在`source_snapshot`，文件身份见`remote_source_receipt.json`。快照是审计材料，不是可运行的完整工程副本。

## 推荐实施顺序

1. **先CPU适配**：审核既有SGBM缓存，编写KITTI加载器；固定200帧输入、K变换、深度单位与无GT接口。先保存协议和配置哈希，再运行。
2. **选择输入路线**：先评估“左RGB+同帧双目派生米制深度”是否能够最小改动复用已运行的RGB-D链。这是候选路线，不是本轮已实现或已验收功能。原生双目路线仍需完整源码审计，暂不承诺一个开关就可用。
3. **独立实现**：将已核验的候选源码复制到CHY专用新路径，记录父版本／补丁；不在`dg_slam_chy_20261011`的队友试验副本上直接修改。权重和大数据只读引用，复制小型配置与源码。
4. **工程冒烟**：先通过投影、深度与位姿转换自检，再确认GPU空闲后运行有界窗口。只有真实进入GS tracking／mapping、产生有限估计轨迹和地图才签管线通过。
5. **200帧对照**：冻结实验配置与重复计划；考虑队友的重复性结论；同机补跑ORB成本基线，再进行完整自主tracking和适用mapping对照。

这一步不会浪费旧成果：ORB轨迹／标定／评价脚本、同帧双目深度工具和mapping评价基础都可复用；固定ORB位姿的Gaussian地图仅作为既有mapping材料，不当作本轮自主tracking结果。

当前尚待：实际R1.1 worker版本追溯、深度缓存单位／来源审计、KITTI加载器、室外配置、传感器路线和mask策略冻结、GPU冒烟及正式对照。队友首次mapping重复性实验不在本目录重做。
