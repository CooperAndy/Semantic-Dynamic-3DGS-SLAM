# A2-0 启发式尺度模型、梯度匹配与建图探索协议

运行前登记。目标是在已有固定 ORB、E6a 双目深度和 isotropic SplaTAM 管线中，比较几何损失的距离尺度/置信度/鲁棒核；不改 RGB、姿态、增点、剪枝或数据。E6a 信心不是真实方差，sigma_d=1 px 是探索假设；没有独立 LiDAR 则不声称噪声模型或误差已校准。

## 模型和对照

现有 mapper 几何项是有效深度像素上的 `mean(|z_obs - depth_sil[0]|)`，后者为 alpha 混合深度和，不是按 alpha 归一化的期望深度。保持该残差和原有 mask，包括 uncovered 位置；无效深度不参与所有组。Huber 采用无量纲转折点 1，`rho(u)=0.5*u²` 当 |u|<=1，否则 `|u|-0.5`，几何损失 `gamma*0.3m*mean(rho(r/s))`。gamma 的作用是匹配初始几何梯度幅度，不是观测噪声标定。

| 组 | 残差尺度 s（单位 m） | 用途 |
|---|---|---|
| B0 | 无；原始 L1 | 基线 |
| B1 | 0.3 | 普通固定尺度 Huber |
| B2 | clip(z_obs²/(f*b), 0.1, 3.0) | 双目一阶尺度 + Huber，视差误差假设 1px |
| B3 | clip(B2尺度 × (1+2(1-c)), 0.1, 3.0) | B2 + 未标定 E6a 置信度启发式 |
| B4 | B0 L1，G07 既有 disp_valid 增点规则 | 对照既有视差机制，控制实际出生数；不是纯损失消融 |

使用各序列 `calib.txt` 中 P2/P3 的相机中心 `-M^-1 p4` 的 x 方向差得到 b、对应像素 fx 得到 f；其采用简化 rectified 一阶模型，P2/P3 的投影矩阵含非零第三行平移，严格 `z=fb/d` 是近似，非精确噪声统计。参数 0.1m/3m、sigma_d=1、confidence 函数均为预先指定的探索值。输入置信度应当有限且在 [0,1]，实际 E6a hard 深度仅保留 >=0.8 像素会限制分布。

## 梯度匹配 DEV

已曝光 KITTI00 A200：C 方案封存的 99 帧地图，帧 85/90/95/98 只作损失梯度尺度匹配，非质量评价；逐文件哈希及相机信息核验。固定相机和图，分别计算 B0/B1/B2/B3 的几何项对 means3D 的 L2 梯度范数；每组的 `gamma=median(norm_B0/norm_Bi)`，要求 4 帧均有限且非零、gamma 在 [0.1,10]。超过范围或样本不足即停止，不自动调参；记录所有范数、输入哈希、gamma。匹配结果在 B200 运行前封存，B200 不参与选择参数。即使匹配有效，也只是工程尺度，不是方差、可靠性或真实深度精度校准。

## 工程与实验

25 帧 smoke 使用 KITTI08 B200 源帧 3000–3024，mapper 留出第19帧；三种损失组和两种增点基线共5臂，同一输入、固定 ORB、相同 seed、初始化、每帧60优化步、原 RGB 项和原剪枝；每个追加帧必须实际增点3000。先做 CPU 合成测试（单位、尺度单调、clip、Huber连续/梯度和失效输入）。无效值、mask 不一致、初始哈希不一致、ID/实际增点或留出帧泄漏、梯度非有限则停止；记录每个输出和失败。

若 smoke 全部通过，5臂重新从零跑 200 帧 KITTI08（源 3000–3199，mapper 留出内部 19,39,...,199）；核对输入 hashes，固定同源相机，封存地图再评分：逐帧 clipped PSNR、SSIM、全图 alpha>0.99 覆盖、三组或五组共同高 alpha+有效 E6a 的期望深度 proxy MAE、成本/峰值显存及点数。E6a proxy 与 RGB mapper 留出均不是独立几何 GT；ORB 和 E6a 上游已看过数据且置信度含邻帧，不能称严格在线或独立 Test。样本数、距离分组、共同支持与全图覆盖必须同时报告。

此 B200 已曝光，仅作单窗口单种子的探索；不预设用一个窗口作质量采用。后续需要另一个冻结窗口、多种子、独立 LiDAR/可靠几何参考，再讨论准确度和创新。若找到真实几何参考，先核查时间、坐标、单位和稀疏分母。A2 不与 A1 同时组合。

每臂 GPU 启动前核查空闲、磁盘剩余>5GiB；每臂最多900秒、CUDA 分配<4GiB，异常保留日志和已完成结果。不得打断其他任务；一旦其他任务运行期间同时使用 GPU，成本对比须标注受影响。
