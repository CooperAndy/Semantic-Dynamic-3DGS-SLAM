# A2 KITTI03 0–199：配对复核协议

## 范围与输入

比较 C0 原深度 L1 和 C2 距离尺度 Huber；C2 gamma=0.7633236491505211，尺度 clip(z²/fb,0.1,3)m，不加置信度项。按 03 P2/P3 完整相机中心计算 fb=384.37173985194534。固定左右双目、RAFT-Stereo、E6a hard depth（confidence≥0.80）、ORB-SLAM3 估计位姿和 RGB 项。其他条件沿用 08：每映射帧 60 次、每追加帧 3000 点、原剪枝；留出帧 19、39、…、199 不参与 mapper 初始化、更新、增点或关键帧。若候选不足 3000 则停止并记失败，不改配额。

按 seed 0、42、2026 各自独立重跑 C0/C2，配对内输入、初始随机状态、per-frame 采样种子及预算一致。不同种子输出保存在不同目录。每组 smoke 为从零处理 25 帧，运行后仅做工程审计，不计算或查看图像、深度及雷达质量分数；保留输出记录但不以 smoke 输出修改参数。全部工程检查通过后才允许全量运行，全量重新从零建图。

## 评分与解释

全量六张图先完成工程审计及地图哈希封存，之后再评分。逐种子报告 10 个 mapper 留出帧的整图 clipped PSNR、SSIM、alpha>0.99 覆盖和每帧差值；E6a depth proxy 在两图共同覆盖/有效区域报告。LiDAR 的 P2 投影只用于建图后评价，按 C0/C2 两图共同 alpha>0.99 有效支持报告逐帧等权 MAE、像素合并 MAE、共同点数、全参考点覆盖率，以及误差截断 5m、未覆盖罚 5m 的合并指标；报告 0.5–10、10–30、30–80m 三桶及每桶帧和点数。没有动态标注，不宣称静态过滤。报告存活点数、显存、时间和 GPU 竞争；共享时不得解释为独占性能。

方向复现的描述规则：3 个配对 PSNR 差都大于 0，称为“本窗口三个种子方向一致”；否则逐一报告，不宣称稳定复现。单个窗口和连续帧不提供跨场景统计显著性。画质、几何、覆盖分别评价，任何一项不能自动抵消另一项；没有预先约定的可接受几何退化量，故无自动正式采用判定，`quality_adoption=false`。不将 0.5 dB 当成门槛，也不根据结果改参数或选种子。

## 数据边界及失败处理

现有 A2 及相关运行登记的有限范围检索未发现 03 被用于 A2 方法选择；全项目历史、模型预训练和相邻场景尚不能穷尽，标记 `CANDIDATE_HELD_OUT_SEQUENCE_LIMITED_AUDIT`，不声称绝对独立。ORB 用全窗口且窗口优化，E6a t−1/t+1 可读取 mapper 留出帧；仅为 mapper 留出，非严格在线或全流程隔离。LiDAR 不用于优化、增点、位姿或深度生成；投影仅近点去重，时差、遮挡和动态仍是限制。

所有输入、投影、方法、配置与协议在首次 smoke 前锁定哈希。输入失配、位姿审计失败、增点不足、非有限值、资源/时间限制、工程审计或渲染失败时停止并保留证据；不跳过失败臂、不换种子、不根据评价结果修调。GPU 使用前检查空闲进程和至少 6144 MiB 空闲显存，磁盘至少 5 GiB；逐臂 900 秒和进程 CUDA 分配 4 GiB 上限；不干扰其他任务。正式运行需单独启动，准备过程不启动 200 帧建图。
