# A2-1 位姿差异及图像/深度区域诊断协议

2026-10-28，事后诊断，不改变 A2 原协议、模型和结果。输入为已封存 B200 五组 200 帧地图、原参考 `orb_adapter_reference.npz`、原 ORB c2w 位姿、相机和评估帧 RGB/E6a；运行前后校验封存地图和使用的输入 SHA-256。只读预测与评分，不读取/使用真实轨迹或几何 GT。

## 1. 位姿微差

沿原 mapper 数据链独立重算：原始 ORB 文本（float64）→ dataset float32 c2w → PyTorch GPU 求逆 w2c → matrix_to_quaternion/set_external → camera/build_rotation → numpy float32 `inv` 输出 c2w。逐步骤对比 A2 五组封存输出 `external_w2c_all_frames`、`estimated_trajectory.npz`、旧适配器 `w2c/c2w`、本次 GPU 重算值。检查批量/逐帧 numpy 求逆一致性及最终输出由其 w2c 重算是否逐值一致；报告各步最大误差、差异元素数和位置、25/200 帧范围。旧参考生成代码、哈希和运行平台信息如可取得一并记录。差异由哪个数值步骤引入只在该步骤被受控实验复现时断言；不可直接把 CUDA 版本、硬件或驱动差异当成已证因果。原 five-map 位姿不更改，不报告定位精度。

## 2. 区域误差与可能机制

统一使用原评分的五图共同 alpha>0.99、期望渲染深度有效、E6a有效且 confidence>=0.8 的像素作为深度比较；RGB 使用全图裁剪 MSE，同时另报共同支持 RGB。对 10 个 mapper 留出帧，报告 B0/B2/B3 的整图 MSE/PSNR、逐 4×4 网格的平方误差之和和样本数、逐深度桶 0.5–10、10–30、30–80m 的代理绝对误差与 signed residual、三图/五图覆盖差异、每帧共同支持数。逐视角 delta 和 pooled 的分母分开，不能把全图图像差异归因于深度共同支持。

在 B0 地图的相同共同像素上，根据预先冻结的 B3 目标函数，计算几何残差对渲染深度的解析梯度绝对值 `gamma*0.3/s * min(|r|/s,1)`，按同样深度桶报告分布、s 的裁剪比例、Huber 二次区比例；B0 L1 的非零残差像素梯度为 1。这里 r 使用 B0 的原始 alpha 深度和与目标的差，与后评分的按 alpha 归一化期望深度不同。该量是单像素损失梯度系数，不是高斯参数的完整梯度，不证明优化效果的因果。不得混合变更参数或事后替换 B3。

保存数值结果和必要可视化（原图、B0/B3、RGB 差异及共同支持深度代理差异），不覆盖原结果。视角和区域由已观察结果选择，全部属于已曝光 DEV、事后解释，无显著性或独立 Test 主张；深度 proxy 不能称真实几何误差。GPU 工作执行前检查空闲、5GiB 余量，分别限 180 秒和 4GiB；异常保留。
