# A2 距离分层评分补充

在 200 帧 5 组留出视角评分前登记：除主评分外，在五张地图共同 alpha>0.99、各自渲染期望深度 0.5–80m、E6a 有效且 confidence>=0.8 的共同像素集合上，以 E6a 观测深度分为 `[0.5,10)`、`[10,30)`、`[30,80)` 米三桶。逐帧每桶报告像素数、每组深度 proxy 绝对误差之和/均值、对应像素的 RGB clipped PSNR；跨帧按像素加总后分别计算 pooled MAE 和 pooled PSNR，不与主报告的逐视角等权平均混为一谈。

这些是以 E6a 自身为深度参考和分桶依据的 proxy/诊断，仅代表五组共同覆盖像素，不衡量无覆盖区域或真实几何误差；完整图像覆盖、逐视角主评分必须并列。原 200 帧预测结果与其他各组参数不变，先核验图/输入哈希，输出留存在 A2 独立目录。无可评分像素的桶报告 null，不自动剔除困难像素后宣称整体改善。
