# A2 计划手册：双目噪声模型驱动的鲁棒几何优化

版本：2026-10-28，研究方案草案。状态：仅计划，尚未实现、冻结、校准或运行 A2。它可以独立检验，也是 A1 的基础对照或后续组合组件；不应把两者的收益相加或预先宣称为创新。

## 1. 问题和假设

在 ORB 位姿固定的双目 E6a + Gaussian mapper 中，不同距离/纹理区域的深度误差不同。假设：经过验证的双目观测噪声尺度加上鲁棒损失，可能比原始深度损失更有效抑制不可靠监督，在相同预算下改善留出视角质量或真实几何。E6a 置信度是候选信息，不天然等于方差或概率。

双目关系 `z=fb/d`，局部一阶近似 `sigma_z ≈ z² sigma_d/(fb)`；f 使用像素单位、b 使用米、d 和 sigma_d 使用像素，深度为相机 Z。近零视差、遮挡、非高斯离群及系统偏差会使一阶近似失效；需要最小有效视差、深度上限和方差上下界，参数先在 DEV 校验，不能把公式当成标定事实。

## 2. 已有工作与实验边界

`../队友阶段三G路线工作说明_20261026.md` 记录 G04/G07 已比较深度残差/等效视差增点，本计划修改几何损失而非声称首次使用视差；必须把既有规则作为参照，并在同一训练设置重跑才能比较。G11 固定回放只是待进一步验证候选；若讨论地图维护，也应在单独实验加入回放对照，避免混杂。

固定 ORB 适合先分离建图；E6a 本身及置信度可能依赖相邻帧，ORB 位姿可能受后续 BA 影响，需核查缓存依赖。已曝光 KITTI00 只作 DEV；E6a 不是独立几何 GT。执行前复查代码、输入、资源、磁盘和服务器结果，不能把 10 月 26 日状态视作实时状态。不同路线的指标和作者贡献不混用。

## 3. 运行前调查与 CPU 准备

1. 明确当前实际深度残差表达、损失归约、遮罩、增点和训练调度；核对相机 fx、baseline、分辨率/缩放、E6a 深度与置信度的单位、范围和无效值；记录源码与缓存哈希。确认双目深度与 RGB 的相机坐标对齐。
2. 查看原数据是否提供同步、标定及可用独立深度/LiDAR。核对相机到 LiDAR 的投影、时间、深度定义和稀疏覆盖；找不到就只能先做代理一致性诊断，不能声称实际误差已标定。
3. 按连续序列/空间块划分校准 DEV、验证 DEV 和独立 Test。校准拟合、超参、鲁棒阈值只能使用校准 DEV；评估帧不得用于 mapper、证据或参数选择。记录 ORB/E6a 是否已接触这些帧，区分 mapper 留出和端到端 Test；同一条轨迹相邻帧不能随机拆分当作独立样本。
4. 用合成数值 CPU 检查 z/disparity 转换、单位、深度边界、无效值、噪声上下界、归约和有限梯度；保证所有消融使用相同有效掩码，记录样本数。

## 4. 噪声模型：先校准后使用

基础模型采用 `s(z)=clip(z²*sigma_d/(f*b), s_min, s_max)`；`sigma_d` 可先在校准集拟合一个常数，或先选一个明确的初始假设做探索。s 是残差尺度候选，不一定是精准标准差。E6a 加入时，用低自由度且有界的 `s(z,c)=s(z)*g(c)`；g 的方向、分段或函数形式、参数和裁剪上下界只能在校准 DEV 上学习，不能直接写作 `variance=1-confidence`。控制样本的距离与纹理分布，检查高低置信度在相同距离区间的真实残差分布。

独立 GT 足够时分深度、视差、置信度和图像位置统计偏差、绝对残差分位数、有效比例及离群率；对标准化残差进行分组可靠性检查，在验证 DEV 上检验残差尺度随深度/置信度的排序与覆盖。GT 稀疏、动态目标或投影边缘需标注过滤/分层。若只有 E6a 自身或同源深度，不可用它验证 E6a 的真实性或声称校准成立。

对未标定情况，尺度模型仅为启发式实验：保留 `unverified` 状态并将其与原损失比较，不写“预测的真实噪声”。参数、拟合数据与哈希、损失权重、最小样本数和模型版本一并封存。

## 5. 几何损失与公平性

定义残差 `r = z_render - z_observed`，先核实当前使用的是期望深度、median 还是其他形式及单位。候选 `L_geo = mean_valid[ρ(r/s)]`，ρ 可从 Huber 开始；Huber 转折点应在校准 DEV 固定，Student-t 为后续独立消融，不同时引入。尺度、有效 mask、总 loss 系数、梯度大小和归约需在运行前指定；调节权重使模型之间具有可比较的起始几何/RGB 梯度量级，并保留原始基线，不根据验证结果反复调权。

权重归一化不可掩盖覆盖或丢弃困难区域；同组掩码、像素数、裁剪比和分距离桶的贡献均需记录。核查渲染 alpha 不足、无效观测及深度遮挡的处理；过低尺度引起大梯度时停止并记录，不静默吞掉 NaN。

## 6. 分阶段实验和对照

先做 25 帧 smoke：检查所有模型运行、有效值、梯度、掩码、追加点数及日志；不以此判断质量。通过后在同一 200 帧已曝光 DEV 窗口进行配对对照，固定 ORB、初始地图、输入、增点、实际点预算、优化步数、分辨率和其他损失：

| 组 | 几何损失 | 目的 |
|---|---|---|
| B0 | 原始损失 | 现有基线 |
| B1 | 仅 Huber，固定尺度 | 排除一般鲁棒核自身的作用 |
| B2 | 距离噪声尺度 + 与 B1 同样 Huber | 检验距离模型的额外作用 |
| B3 | 距离 + 经校准或标注为启发式的 E6a 置信度尺度 + 同样 Huber | 检验置信度是否额外有用 |
| B4 | 与 B0 同损失、已有等效视差增点规则 | 对照已做过的相关机制；固定实际出生点数 |

为了分离噪声归一化和鲁棒核，可在有资源时增加固定尺度/距离尺度下相同非鲁棒核的配对；B4 同时改变增点，不能解释为纯损失消融。所有权重或尺度参数在校准 DEV 选定后冻结，在不同验证窗口及多个种子复验。单窗口单种子只能称探索性。

留出帧评价 clipped PSNR、SSIM、固定目标区域覆盖、未覆盖率；有独立真实深度时报告深度误差及距离分层，E6a 一致性另列为 proxy。共同有效支持与全目标覆盖同时报告；保留逐视角结果和样本数。记录实际追加点、最终点数、时间、峰值显存、异常及梯度统计；设置主要指标、最低可评分量、覆盖/成本容忍线及失败规则后才跑冻结验证。

继续条件：相较 B0、B1 和 B2，候选在预先指定的独立主要评价指标上有跨窗口、跨种子的稳定增益，覆盖与成本满足预设限制；若 B3 没有超过 B2，就不能声称 E6a 置信度提供额外价值。只提高 E6a 自一致性而没有独立质量收益，属于代理信号。正式 Test 只在开发完成、方案冻结后使用；不存在独立 Test 时明确缺口。

## 7. 与 A1 组合及后续

当 A1 和 A2 各自具备冻结的独立结果后，以 2×2 对照：原/最佳 A2 几何损失 × 无/有 A1 证据权重。固定所有其他设置，检查二者交互和总成本；不要在 A1 同时引入新损失、剪枝及增点改动。建图有效后，另行设计 tracking 正控和 ATE/RPE；固定 ORB 地图评价不能证明定位收益。

若无有效标定数据、模型不稳定、单位/坐标无法核对、验证泄漏或资源不足，停止对应阶段并说明缺口；不把拟合值描述为传感器真值。本手册不授权启动 GPU 或改写现有结果。
