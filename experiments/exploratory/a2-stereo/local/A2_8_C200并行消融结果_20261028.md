# A2-2 KITTI00 C200 并行对照结果（2026-10-28）

## 结论与范围

六组 25 帧工程 smoke、一个 KITTI00 200 帧窗口六组建图、独立工程审计、10 个 mapper 留出视角的 RGB/E6a 评分与稀疏 LiDAR 评分均完成。C2–C5 在本窗口呈现图像改善信号；C3 和 C5 对 LiDAR 的共同覆盖误差比 C0 L1 更大。相对 C3，降低尺度上限的 C5 在中远距离 LiDAR MAE 只下降约 0.76% 和 1.67%，均不足预登记的至少一个桶改善5%条件；因此不推进原计划的多窗口多种子扩展。此结论只针对当前单窗口单 seed，不等于 A2 已经失败，也不证明鲁棒损失改善真实几何。`quality_adoption=false`。

窗口 KITTI Odometry 00 源帧3500–3699、内部0–199，mapper 留出19、39、…、199；历史已曝光 DEV、固定 ORB、E6a confidence 和位姿存在未来帧依赖，不是严格在线或全新独立 TEST；不能得出 ATE/RPE 或定位收益。10个对应 LiDAR 测量只在建图完成后评分，未用于双目/E6a、增点、地图优化或位姿。LiDAR 采样稀疏、相机与雷达存在视点差、扫描时差及动态物体；未获取语义标签过滤动态对象，渲染深度为 alpha 归一化混合深度；独立的测量来源不代表密集真值或完全无误差。

## 组别与工程核验

C0 为原 L1；C1 固定尺度Huber；C2/C3 为上限3m且分别不使用/使用置信度；C4/C5 为上限1.5m且分别不使用/使用置信度。C2–C5 用相同 gamma 0.7633236491505211，C1 用已封存的1.0010791602334679；KITTI00 特定的 fb=383.3593894935312 px·m。所有噪声尺度和 E6a 的启发式映射均未独立标定为方差。

25帧六组自身完成且独立工程审计PASS。200帧六组独立工程审计PASS：初始地图哈希一致，六组各189次追加、每次3000个、共567000个新增；实际最终存活数 C0/C1/C2/C3/C4/C5 分别为 601527/599291/629782/630688/623945/622760。每组位姿数组彼此逐值一致；相对参考适配器旋转最大分量差3.61e-7，平移最大分量差4.77e-5m，在既定容差内；不代表定位误差或轨迹精度。

首次 smoke 因运行器引用错误 worker 文件名，C0在训练前退出，批次记录和日志完整保留；修正后重跑成功，结果不得称首次无误。25帧评分 JSON 的描述文本误写 KITTI08，实际读取并渲染 C200 KITTI00，相关输入及哈希检查可复核；原文件不覆盖，200帧评分代码文字已纠正。

用户明确同意与其他任务共享GPU。200帧 C0、C1、C4 在10秒抽样中观察到其他GPU进程，C2、C3、C5 没采样到不证明独占。每组墙钟约275–295秒，不能作为公平独占性能对比；峰值PyTorch分配 C0/C1/C2/C3/C4/C5 约802/803/824/1196/822/1193 MiB。训练期间只做了有限梯度检查，未采集完整训练几何梯度分布，不用此推断成因。
