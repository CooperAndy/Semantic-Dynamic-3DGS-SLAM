# A2 双目噪声尺度与鲁棒几何优化：研究总结

整理日期：2026-10-29

## 1. 结论和当前状态

A2 已完成第一轮方法实现、六组消融及 C2 跨窗口复核。当前保留 **C2 作为改善渲染画质的候选方法**：在两个已曝光窗口中，相对 C0 的 PSNR 和 SSIM 均提高，但在两个地图共同覆盖的稀疏 LiDAR 参考点上，深度 MAE 均上升。它存在图像质量与几何一致性的取舍，尚不能称为全面改善几何，或已正式替换原管线（`quality_adoption=false`）。

两个窗口每个都只有一个种子，而且此前均已曝光；10 个留出帧来自连续序列，不是 10 个独立场景。所有建图实验固定 ORB 位姿，不支持定位、ATE 或 RPE 提升的结论。下一步需要预先冻结 C2 和评价方式，在未曝光数据上比较，并进行多种子重复。

## 2. 研究目标与输入边界

原管线采用双目输入，使用 E6a 深度和原有高斯建图；C0 使用原有深度 L1 损失。A2 借用双目测距误差随距离增大的规律，引入距离相关的残差尺度和 Huber 鲁棒损失，研究它们对建图结果的影响。距离关系来自 z=fb/d 和一阶近似 σz≈z²σd/(fb)，但本实验的尺度截断、假设视差误差及置信度映射均未经过真实噪声标定，属于启发式设计，不能称为已准确估计传感器方差。

**输入方式没有改变：**双目、E6a、固定 ORB 位姿、RGB 损失和原有建图流程继续使用。LiDAR 只在地图完成后用于独立稀疏几何评价，不用于生成双目深度、选点增点、地图优化或位姿估计。LiDAR 来自独立测量，但稀疏采样、时差、遮挡、动态物体和渲染深度的 alpha 混合仍可能影响误差，不能把它当作无误差的稠密真值。

## 3. C0–C5 各方法

设 r 为原 mapper 中 alpha 混合渲染深度与 E6a 深度的残差，z 为观测深度，c 为 E6a 置信度，fb 使用对应序列的标定。C2–C5 共用 γ=0.7633236491505211，使用 γ×0.3m×mean(Huber(r/s))，Huber 转折点为 1。基础尺度 b=clip(z²/(fb), 0.1m, 3m)，置信度因子 q=1+2(1−c)。不使用置信度时 q=1；使用时 s=clip(b×q, 0.1m, 3m)，再根据组别设置最终上限。数值尺度和 γ 的作用是启发式尺度及既有初始梯度幅度匹配，C2–C5 采用同一个 γ 不意味着相对 C0 排除了整体梯度量级变化。

| 组别 | 具体方法 | 用途 |
|---|---|---|
| C0 | 原始深度 L1 损失 | 原有建图管线基线 |
| C1 | 固定 0.3m 尺度 Huber，γ=1.0010791602334679 | 只引入普通鲁棒损失的基线 |
| C2 | 按距离 b 设置尺度，不加入置信度，最终上限 3m | 测试距离尺度；当前候选 |
| C3 | 按距离及 q(c) 设置尺度，最终上限 3m | 在 C2 上测试置信度因子 |
| C4 | 与 C2 相同，但最终尺度上限降为 1.5m | 测试尺度上限变化 |
| C5 | 与 C3 相同，但最终尺度上限降为 1.5m | 联合测试置信度与较低上限 |

上限从 3m 降到 1.5m 会影响所有超过 1.5m 的尺度，不仅影响某个远距离区间。C3−C2 与 C5−C4 用来观察置信度因子的经验效果，C4−C2 与 C5−C3 用来观察上限变化。由于置信度未被校准成真实方差，这些对照不能证明其统计意义上的噪声估计准确与否。

历史 B2 与 C2 不相同：B2 的 γ=0.6053887836535369，不能把历史 B2 成绩当成 C2 的跨窗口复核；C3 的损失形式和 γ 与历史 B3 对应，但本次数据窗口与标定不同。

## 4. 六组主要消融结果：KITTI 00 C200

窗口为 KITTI Odometry 00 源帧 3500–3699，内部帧 19、39、…、199 为 10 个 mapper 留出视角；单种子 seed 0，固定 ORB 位姿。每个非留出建图帧 60 步，各组初始地图哈希相同、位姿组间逐值一致、各自追加 189×3000=567,000 个高斯；剪枝与优化会导致最终存活数不同。实验在共享 GPU 授权下运行，运行时间不能视为独占性能比较。

下表的 PSNR、SSIM 和整图 alpha>0.99 覆盖为 10 帧逐帧等权均值；E6a proxy 与 LiDAR MAE 分别在**六张地图的共同有效覆盖**上逐帧等权计算。E6a proxy 是与输入深度的一致性，不是独立真值；LiDAR 覆盖率是在全部有效参考点上统计。共同覆盖与全部参考点的分母不同，不能只看 MAE 忽略未覆盖点。

六组共同 LiDAR 支持包含 70,509 个点像素，全部有效参考为 193,390 个点像素。C2 相对 C0：PSNR +0.34542 dB、SSIM +0.015834，整图覆盖 +0.3099 个百分点；六图共同支持 LiDAR MAE +0.01528m。C3 的画质分数最高，但比 C2 仅高约 0.00805 dB，六图共同支持 LiDAR MAE 高 0.01064m，整图和 LiDAR 参考点覆盖也较低。因此结合画质和几何取舍，保留更简单的不含置信度项的 C2 作为候选，并不表示其几何优于 C0。

C5 相比 C3 在 LiDAR 中距和远距桶的 MAE 分别下降约 0.76% 和 1.67%，未达到该比较事前规定的至少一个桶改善 5% 的条件，且两个桶相对 C0 仍更差；因此原定的完整六臂多窗口多种子扩展没有执行。此 5% 条件针对 C5 相对 C3 的几何比较，不是对 C2 图像收益设定的门槛；也没有将 0.5 dB 作为本次 C2 通过标准。

## 5. 固定 C2 的跨窗口复核

复核使用 KITTI Odometry 08 源帧 3000–3199，同样留出内部 19、39、…、199，seed 0。C0 和 C2 均重新建图；固定 C2 的 γ 和其他设计，仅按序列真实标定使用 KITTI08 的 fb=378.6112506585076 px·m（KITTI00 为 383.3593894935312）。两组初始地图和位姿相同，均追加 567,000 个高斯；最终 C0/C2 存活数为 553,858/570,937。两组工程审计通过。

下面两窗口的 LiDAR MAE 均使用 **C0 与 C2 两图的共同覆盖**，因此 KITTI00 数值是对已有地图事后重新评分，与上一节六图共同支持的 LiDAR MAE 不同，并非建图结果改变。两窗口之间参考点、场景和共同覆盖不同，重点比较各窗口内的配对差。

KITTI00 的 10/10 个留出帧 PSNR 改善；KITTI08 为 8/10，另两帧下降约 0.1817 和 0.0151 dB。KITTI08 的共同支持 LiDAR MAE 在 10/10 帧均高于 C0；末帧只有 545 个共同参考点，但仍按既定规则与其他帧等权。KITTI08 去除有标注的移动类别 252–259 后，事后敏感性分析的 MAE 为 1.19715→1.25427m，仍上升；这并不保证已剔除全部动态或遮挡影响。

为反映未覆盖点，另计算绝对误差截断 5m、缺失罚 5m 的参考点合并指标：KITTI00 C0/C2 为 3.05273/3.03690m，KITTI08 为 3.15208/3.12257m。它综合了误差与覆盖，5m 是工程常数，C2 的较好数值与更高覆盖同时出现，不能单独作为几何更准确的证据。

## 6. 审计与已有局限

六组 25 帧 smoke 与 200 帧建图的独立工程审计均通过；最初一次 smoke 因 worker 文件名错误在训练前退出，修正后重跑，失败记录已保留。位姿最初的严格逐值参考检查未通过，但各实验组相互逐值一致；追踪发现历史与本次 GPU 求逆最早已出现微小浮点差异，具体硬件或库原因未确定。后续参考容差检查通过，这不是定位精度评价。

LiDAR 投影及误差计算经过独立 CPU 重算，但这类算术复核不能消除传感器扫描时差、动态物体、跨视角遮挡或地图绝对系统误差。KITTI08 旧版 C0 和本次 C0 的图像分数存在约 0.04444 dB 差异，原因尚未确认，提示应做重复实验，不应指定未经证实的成因。ORB 和 E6a 缓存可能使用未来帧，因此本轮也不应宣称严格在线。

## 7. 下一步：未曝光数据与多种子验证（尚未执行）

1. **冻结方法与评价。** 在查看新结果前固定 C0、C2 的实现、γ、数据筛选、预算、距离分层、覆盖/共同支持口径、失败处理和报告规则；fb 使用每个序列的真实标定。不要根据测试结果继续调整 C2。选择未曝光且尽可能空间独立的序列或窗口，核对双目、E6a、ORB 和相机/LiDAR 的帧号、标定、同步及上游是否已接触测试数据，登记来源与哈希。若新数据已参与过调参，就标为 DEV，而不是独立 TEST。
2. **多种子配对。** 在预先选定的窗口运行 C0/C2 的相同种子配对，建议至少 3 个事先登记的种子；每个种子保持两组输入、初始化条件和预算对应。逐窗口、逐种子报告差值及波动，种子是重复运行，不等于独立场景。若条件允许，再增加空间独立窗口或序列，分别报告，避免只给混合平均。
3. **同时评价画质和几何。** 报告整图 PSNR、SSIM、整图覆盖、每帧配对结果、共同覆盖 LiDAR MAE、分距离 MAE、有效参考数量、各组 LiDAR 覆盖和缺失惩罚指标；有可靠语义标签时将动态类别过滤作为额外敏感性检查。记录高斯出生与存活数、显存、计算成本和 GPU 共享情况。E6a 一致性只作代理指标。
4. **根据实际用途决定是否采用。** 比较图像收益能否稳定复现、几何误差和覆盖变化是否可接受，并在运行前写明决策规则；不要把较低图像提升自动判为失败，也不要掩盖几何退化。若条件无法提供可核验的独立几何参考，结果只能形成画质和代理深度证据。若日后要声称定位收益，还需另行设计允许位姿估计变化的实验及 ATE/RPE 评价。
