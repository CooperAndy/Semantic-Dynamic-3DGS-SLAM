# C 稳定 ID 诊断协议

2026-10-27，运行前确定。采用 G07 A200 相同 200 帧已曝光 DEV 输入、固定 ORB、seed0、native 候选及实际每追加帧 3000 点。新增点按追加顺序赋不可重用 int64 ID；剪枝时同步过滤 ID，并保存删除 ID；99 帧快照与最终地图保存 ID 和出生帧。ID 仅存变量和快照副本，不进入优化参数或损失。

先复核此记录版与本机此前 B 对照 N0 的初始化、相机、最终地图参数是否逐值相同；若不相同则保存差异，先查明记录是否改变行为，不能直接称为完全复现。必须核对存活/删除 ID 守恒、ID 唯一与长度对应、同 ID 出生帧一致。

通过身份审计后，以99帧快照中的点为早期点，匹配最终存活 ID；报告同点位置、RGB、尺度、透明度变化及早期删除量。对最终完整地图，只将匹配早期存活点的一个参数组还原到99帧值，分别为位置、颜色、尺度、透明度，其他参数和后期点保持最终状态。原最终图为基线；对10个建图预留视角做共同相机渲染，报告逐视角PSNR/覆盖/E6a代理和相对深度变化。

这是事后受控渲染诊断：不等于用长基线三角化的新锚点，也不等于在线冻结位置会产生相同效果。已删除的早期点不放回，不把幸存点变化代表所有早期点；无 GT tracking/ATE 或独立 Test。只有定位或地图指标支持进一步研究时，才另行设计真正在线锚点干预。
