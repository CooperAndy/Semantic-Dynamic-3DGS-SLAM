# C 稳定 ID 与同点参数还原验证

2026-10-27。**完成一轮 200 帧原生建图、完整稳定 ID/剪枝审计、两次 25 帧无 ID 记录重复检查，以及 6 条件 × 10 视角共 60 次受控渲染。** 按用户最新指示与 G13 共享 GPU，全部耗时不可用于性能比较。

结论：本运行的早期存活点确实发生位置变化，但把它们的位置还原到99帧快照没有改善早期平均画质或 E6a 深度代理；还原颜色则改善早期画质。当前结果支持继续检查外观维护，不足以支持直接实现几何锚点，也不证明具有可靠长基线几何的锚点无效。

本轮是新运行的99→199短窗口探针，与原先G09的199→999长流诊断不同，不能直接把本轮效应量外推为原1000帧运行的原因分解。

## ID 记录与可靠性

使用 G07 A200 同一暴露 KITTI00 窗口、固定 ORB、seed0、E6a、native 候选，每追加帧实际3000点；200帧中的10个建图预留视角为19、39、…、199。ID 保存在变量与快照副本，不进入优化器参数。初始化和每次追加分配单调 int64 ID，剪枝同步过滤ID且保存删除ID；不重复使用已删除ID。记录模块先通过 CPU 的追加、删除和快照对齐测试。

审计程序从初始ID、189次追加事件和全部删除ID重新构造ID序列，逐值匹配0、99、198快照及最终地图的 ID 和出生帧，并检查ID唯一、删除不重复和总量守恒：

- 初始 96,362 点，追加 567,000 点，共创建 663,362 点。
- 共删除 49,239 点，最终 614,123 点；创建数=删除数+存活数。
- 99帧快照有359,436点；最终匹配340,320个同ID早期存活点；19,116个早期点后来被删除，约5.32%。
- 相同存活ID的出生帧一致，未凭数组位置或最近邻猜测身份。

同ID早期存活点99帧→最终：位置欧氏变化中位数0.03280 m、p90 0.08306 m、最大0.43369 m；RGB通道绝对变化中位数0.1114、均值0.2219；尺度相对变化绝对值中位数13.59%；opacity绝对变化p90约0.3194。它们是实际同点变化，但**位置移动不等于位置变错**，旧位置也不是几何真值。

## 逐值复现局限及处理

最初严格复现检查未通过：本次记录运行最终614,123点，此前N0为614,277点；初始地图哈希及固定相机完全一致，但原生优化很早就出现候选差异。原 `analyze_render.py` 在此明确停止，保留 `analysis.log`，未把它报告成成功复现。

随后进行两次**均不带ID记录**、相同初始化和相机的25帧重复运行，最终分别160,916和160,935点；第1帧候选与选择一致，第2帧候选开始不同，第3帧选择也不同。说明该运行条件下无记录流程本身也不保证逐值重复。此实验没有单独确定不重复的底层原因，亦不能据此证明所有差异都由GPU计算造成。

后续 `analyze_render_v2.py` 因此仅使用本次记录运行自身作为渲染基线，明确不把旧N0当作同一地图。ID守恒和出生帧对齐均通过；基线119、199帧的重渲染与本次运行封存的工程渲染逐值相同。初始协议、记录代码和源码哈希未变；后续分析及重复性证据另锁哈希。

## 受控渲染设计

以最终完整地图为基线，通过ID找到99帧快照中同一批早期存活点，分别只把它们的位置、颜色、尺度、透明度还原为99帧值，另加全部早期参数同时还原作为辅助条件。后期点与相机保持最终值；被删除的早期点不放回。所有组使用相同最终相机和图像/深度输入，只有列明的参数组变化。RGB/深度输入与原清单哈希匹配。

这是**幸存点的事后参数还原**，不是在线冻结或外部几何锚点，参数间有共同优化和遮挡交互；任何单组效果都不能外推为在线干预会得到相同结果。深度统计为六种地图共同alpha>0.99、0.5–60m且E6a有效像素上的期望深度误差，非真实深度精度。共同像素每视角20,694–78,042个，结论限于该支持区域。

### 早期5视角（19–99）

|---|---:|---:|---:|---:|---:|
| 最终地图 | 11.424 | — | 12.583 | 52.33% | 0.5045 |
| 仅位置 | 11.265 | −0.159 | 12.354 | 52.44% | 0.5201 |
| 仅颜色 | 13.213 | +1.789 | 13.513 | 52.33% | 0.5045 |
| 仅尺度 | 10.359 | −1.065 | 11.457 | 43.04% | 0.4036 |
| 仅透明度 | 11.352 | −0.072 | 12.492 | 52.32% | 0.6427 |
| 早期参数全部还原 | 12.326 | +0.902 | 12.600 | 44.43% | 0.4001 |

仅位置还原在帧19是−1.265dB，其余四视角有3个小幅改善，平均值受帧19影响，不能说每个视角都不受益。仅颜色还原5视角中4个改善，帧19反而−0.742dB；早期裁剪PSNR均值也提高0.930dB，所以改善并非完全来自未裁剪越界值。仅颜色还原的深度与覆盖逐值不变，符合渲染接口。

### 后期5视角（119–199）

仅颜色还原原始PSNR相对最终图−0.076dB，裁剪PSNR−0.079dB；位置还原−0.023dB。139及之后视角中受还原的早期点影响很小，不能把这些零差异当作独立成功验证。

十视角整体均值：最终原始PSNR11.632dB、仅位置11.541dB、仅颜色12.488dB；最终覆盖47.98%、位置48.05%、颜色47.98%。细节见`结果/controlled/summary.json`。不同单参数还原的效果不保证可相加。

## 对 C 的含义

现在能证明在此运行中旧点确实改变过，也能对相同存活点分别检查参数影响。当前结果并未显示把早期位置还原就能修复平均退化；颜色还原更有效，但这是对已有外观维护问题的解释，不是新的已验证创新。具有外部可靠几何的长基线锚点与“还原到旧快照坐标”不同，本轮无法判断前者是否有效。

因此不建议根据现有证据直接投入完整C锚点实现。若继续，应先明确外部锚点的真实几何来源、相机/深度误差与定位评价，再做在线干预；不能把事后画质变化称为tracking、ATE/RPE或独立Test收益。本轮为单窗口单种子的探索性研究，没有质量采用。
