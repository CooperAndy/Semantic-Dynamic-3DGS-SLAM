# G19-C：过去帧置信度与因果输入回放

本轮B负责输入准备与失败检查，A/B接口仍为左目对齐、米制float32深度.npy（0为无效）与P2 C2W 12列位姿；不改G14、G18-D或G19前端产物。输入为已暴露的KITTI08 3000–3999，不是新测试窗口。

旧G14置信度先读完整窗口深度与最终ORB轨迹，并取t−1/t+1的最大时间一致性。本轮保留原LR/光度/时间重投影数值函数，改为流式读取当前双目图、当前左右深度、当前已封存即时位姿；只保留前一帧左深度与位姿。t=0无时间证据，乘数固定为1；其余只与t−1比较。源图与RAFT左右深度复用原冻结的逐双目对推理，不重跑GPU。

参数沿用G14：深度选择0.5–40m、seed≥0.80、loss≥0.20、LR sigma1px、photo sigma0.10、temporal sigma0.10；源深度仍是0.5–80m米制。标定、语义策略、网络权重不调优。新输入改变各组共用观测，不能把新旧输入之间的质量差归因于tracking/history方法。

验收：1000组有限float32置信度/深度与bool掩码；hard depth逐像素等于源左深度乘seed；所有有效深度满足原范围；原函数字节保持；已知平面运动、边界与首帧控制通过；输出封存前不打开下一帧图像、深度或位姿记录；全部5000输入SHA与产物SHA复核；GT访问为0。strace涵盖全部线程的openat/write，独立审计每帧封存与读取顺序。前端本身的因果性由G19原审计保证。

预算：CPU-only（CUDA_VISIBLE_DEVICES为空），OMP2/BLAS1，准备600秒、生成1200秒、审计600秒，私有树≤6GiB，逐帧保留10GiB数据盘余量。若预算/内容检查失败保留全部旧产物与日志，不覆盖重启。当前共享负载耗时仅为预算记录。

这是带因果依赖的缓存回放输入，不是实时端到端系统、正式速度结果或质量采用。后续仍须把稳定出生几何修正统一接入新的联合配置，并完成真实tracking/mapping质量门及两窗三seed。
