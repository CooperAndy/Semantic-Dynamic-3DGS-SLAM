# G21-INPUT：跨窗口因果前端准备

B负责输入、前端和失败账本；A/B深度/位姿/掩码接口不改。本轮固定两个观察窗：KITTI05源000000–000999、KITTI10源000000–000999，各1000双目对。选择依据为现有数据完整、固定首1000帧及足够历史长度；先于本轮任何GT质量评分登记，不根据前端成功率/ATE或建图质量替换窗口。只准备输入，不启动Gaussian、RAFT或正式比较。

复用G19已审计的同一CPU二进制、词典、核心库和参数。实际PNG尺寸、P2/P3内参及有效水平投影基线必须与该参数一致；不一致则停止该窗并保留失败。图像以只读符号链接引用既有数据，时间戳截取并以本窗首帧为零。每帧TrackStereo返回后立即封存Tcw、状态、map和C2W，下一帧图像随后才可读取。完整源码/ABI与运行库父链仍由G19科学包提供。

全线程strace审计2000唯一图像与1000封存事件、无超前图像读取、无GT文件访问；独立检查1000矩阵/源ID/时间戳/逆矩阵。仅全部状态OK=2、位姿有效且单map时发布主C2W；任何失败保留全分母、NaN、状态和地图事件，不插值、不裁掉失败帧。停机后最终轨迹仅作两估计差异检查，不作为即时建图输入或GT。

固定失败分类：前端非OK帧、无效位姿帧、地图ID变化/地图事件独立记录；进程中止、资源超限另记run failure。Gaussian优化拒绝与前端丢失分别报告。未来完整系统失败门还须核验所有实际输出与运行中止，不能仅以共用前端0丢失替代。

预算：CPU-only，两个窗口顺序执行，单窗1800秒、审计300秒；限定4个可用CPU核，BLAS1/OMP2。仅此任务私有进程组可被预算停止。原始引用图像不复制；私有非链接树≤1GiB，压缩科学包合计≤5GiB，保留8GiB。科学包包含实际图像字节供本地恢复；逐成员及全部G19父引用通过后方可转存服务器压缩副本，原始数据保留。

本轮是预登记窗口的输入可行性准备；此前项目可能接触过这些数据，不宣称盲测或独立前端seed。正式候选/对照矩阵在G20之后另冻结，至少两窗口×三后端seed及原质量/退化/失败门保持。无GT评分、无方法采用、无公平FPS或端到端实时结论。
