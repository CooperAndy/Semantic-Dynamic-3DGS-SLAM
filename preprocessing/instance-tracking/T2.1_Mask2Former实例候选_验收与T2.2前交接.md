## 3. 修复内容

1. 将 instance checkpoint 的 `0–7` 类别 ID 显式映射到 dense Cityscapes-19 的 `11–18` ID。
2. 对每个实例保存 `dense_semantic_ids`，并重新计算可复核的 `dense_semantic_agreement`。
3. 增加确定性同类 mask NMS：IoU 大于等于 0.30，或较小 mask 被包含大于等于 70% 时抑制较弱 query。
4. 去重排序固定为：dense agreement、模型 confidence、mask area。
5. 过滤 dense agreement 低于 0.10 的类别不一致 query。
6. 模型加载必须满足 missing、unexpected、mismatched 和 error keys 全为空。
7. verifier 增加模型权重 SHA256、dense manifest SHA256、类别映射、agreement 重算、同类重复 mask 和轨迹类别一致性检查。
8. 原脚本已在服务器保留 `.pre_codex_20260901_1330` 备份。
