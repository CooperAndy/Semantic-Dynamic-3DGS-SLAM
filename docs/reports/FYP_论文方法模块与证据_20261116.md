# FYP 论文方法模块与证据

核对日期为 2026 年 11 月 16 日。方法覆盖 **车辆动静判定、地图辅助位姿校正、带长间隔关键帧回放的语义高斯建图，以及建图后颜色与不透明度精修**。按输入输出与职责拆成 12 个模块。TSDD 和 SUC 留在历史实验记录中。官方轨迹、LiDAR 和 SemanticKITTI 标签属于离线评价。 [当前框架图](fyp_overall_framework_pi3mos_f1.drawio) · [流程审计](fyp_pipeline_audit.md)

标题中的【已有方法】指直接采用的核心算法，【已有方法＋团队适配】指外部模型或建图骨架加上项目自己的处理规则，【团队方案】指团队自行设计或实现的模块流程。标注依据是项目源码和归档。论文层面的新颖性需要通过相关工作比较建立。

涉及陈泓逸展示实现的模块，依据实际 Demo 源码描述方法机制；深度置信度阈值等配置按每张地图的候选比较和验证结果选择，不将某一场景的特调数值写成通用设置或全局最优。具体地图配置仅作为可追溯依据。下文保留原有团队目标流程和阶段三实验记录，并区分离线展示与在线接口；单张展示图不作为全部 12 个模块已共同启用的证据。[展示配置参考](../阶段2/动态语义Demo_设计/T07_动态语义独立副本/源码/scene-config.kitti09-c50-s42.json)

## 1. 方法有哪些模块

| 论文小节 | 模块 | 主要输出 |
|---|---|---|
| 逐帧几何观测 | 模块1. 双目相机位姿估计（Stereo Camera Pose Estimation）【已有方法】<br>模块2. 双目深度估计与置信度评估（Stereo Depth Estimation and Confidence Assessment）【已有方法＋团队适配】 | P2 左目米制位姿、米制深度、深度置信度 |
| 逐帧语义与运动观测 | 模块3. 场景语义分割与实例跟踪（Scene Semantic Segmentation and Instance Tracking）【已有方法＋团队适配】<br>模块4. 车辆动静判定（Vehicle Motion State Classification）【已有方法＋团队适配】<br>模块5. 动态车辆像素屏蔽（Dynamic Vehicle Pixel Masking）【团队方案】 | 语义类别及实例 ID、车辆状态、后续模块可使用的像素 |
| 定位 | 模块6. 地图辅助位姿校正（Map-Assisted Pose Correction）【团队方案】<br>模块7. 按类别筛选特征匹配（Feature Match Filtering by Semantic Class）【团队方案】 | 当前选中位姿、下一帧位姿预测的起点 |
| 地图增长与保持 | 模块8. 高斯地图增点与优化（Gaussian Primitive Insertion and Map Optimization）【已有方法＋团队适配】<br>模块9. 长间隔关键帧回放（Replay of Temporally Distant Keyframes）【团队方案】 | 增量高斯地图、对早期视角的持续约束 |
| 语义地图 | 模块10. 多视角语义投票（Multi-View Semantic Voting）【团队方案】<br>模块11. 语义约束的高斯几何优化（Semantically Constrained Gaussian Geometry Optimization）【团队方案】 | 每个高斯的类别分布、参与几何优化的类别一致性梯度 |
| 地图外观精修 | 模块12. 建图后颜色与不透明度精修（Post-Mapping Color and Opacity Refinement）【团队方案】 | 与在线地图同点集、同相机的精修副本 |

一对 KITTI 双目图像进来，ORB 先估计车载相机走到了哪里，RAFT-Stereo 估计图上各处离相机多远。左目画面同时提供类别、实例轮廓和车辆运动概率。位姿校正模块用这些观测与上一时刻的地图挑选当前位姿，SplaTAM 按该位姿更新地图。定位时按类别一致性筛选匹配，定位和建图时屏蔽动态车辆像素。已有高斯的历史语义为建图提供额外的几何约束。每个建图帧结束后，新地图和选中位姿进入下一帧。整段建图结束后，系统复制地图并精修高斯的颜色与不透明度，随后可以用同一套相机比较前后两张地图。

## 2. 每个模块怎么做、为什么用、为什么能起作用

### 模块1. 双目相机位姿估计（Stereo Camera Pose Estimation）【已有方法】

- **工作流程**　读取同步的 `image_2`、`image_3` 与 P2/P3 标定。逐帧调用 ORB-SLAM3 的 `TrackStereo`，记录即时返回的位姿、跟踪状态和帧号，导出 P2 左目米制轨迹。位姿校正模块以相邻 ORB 位姿的相对运动作为当前预测的运动增量。 [G19 即时位姿账本](../阶段3/G19_因果前端与失败账本_20261029/G19_执行与因果输入报告_20261029.md)
- **为什么用**　高斯地图刚开始很稀疏。先用双目前端给出相机的初始位置与朝向，每帧都能在一个已有的坐标系里放深度观测。
- **为什么能起作用**　已知双目基线给三角化提供米制尺度，同一场景特征在连续图像的位置变化给出相机运动约束。G19 在 KITTI08 的 1000 帧开发窗逐帧封存即时估计，账本记录 0 次无效位姿和 0 次读取真值。这个结果验证的是该窗输入与时序。 [G19 即时位姿账本](../阶段3/G19_因果前端与失败账本_20261029/G19_执行与因果输入报告_20261029.md)

### 模块2. 双目深度估计与置信度评估（Stereo Depth Estimation and Confidence Assessment）【已有方法＋团队适配】

- **工作流程**　由 RAFT-Stereo 估计左右视图的视差，用 `Z = fₓ B / d` 将左目视差转为米制深度，其中 `fₓ` 为水平焦距、`B` 为双目基线、`d` 为视差。展示采用的离线置信度综合左右往返一致性、光度重投影误差，以及用 ORB 估计位姿与前后相邻帧 `t−1、t+1` 比较的几何一致性；可用邻帧的时序置信度取最大值，再与双目置信度相乘。根据每张地图的重建表现、有效深度覆盖和计算成本比较候选置信度阈值，选择适合该地图及当前目标的设置，再将筛选后的可靠深度用于建图；这是按地图验证后配置，不是已实现的逐帧自动阈值调整。有效深度范围及深度损失的支持区域按实际输入单独登记，生成了某张 mask 不等于 mapper 已单独消费它。阶段三因果版本另将时序证据限制为当前及过去输入，其定位支持配置与离线展示分别记录。[置信度实现参考](../特调地图/seq09_seed42_交付校验/evidence/mapping_scripts/build_depth_confidence_kitti.py) · [按地图比较阈值的实现参考](../特调地图/tune_f1_seq09.py)
- **为什么用**　估计位姿时需要知道参考特征在三维空间里有多远，建图也需要深度才能放置高斯。遮挡边缘、反光、弱纹理处容易匹错，所以还要估计每个深度值可信到什么程度。
- **为什么能起作用**　左右都能对应、投过去颜色接近、短时三维位置也能对齐的像素，通常有多条支持证据。按置信度选择观测，可以减少错误深度参与求位姿或反投影；按地图比较阈值则在可靠性与覆盖之间选择合适的取舍。双目置信度是可靠性代理，错配、远处小视差和运动物体仍会影响它。阶段三因果生产账本记录了每帧的最晚输入索引与上一帧索引；前后邻帧离线置信度不据此称为严格因果输入。

### 模块3. 场景语义分割与实例跟踪（Scene Semantic Segmentation and Instance Tracking）【已有方法＋团队适配】

- **工作流程**　用 Mask2Former 从当前左目 RGB 生成 Cityscapes-19 类别、语义置信度、实例掩码及检测信息。Seq09 展示采用 RAFT 前向光流与 `FlowWarpTracker` 辅助实例关联：将上一帧实例掩码按光流变换，与当前检测关联并分配 `track_id`。逐帧保存实例类别、检测置信度、边框及 `mask_index` 对应的原始掩码，供 Pi³MOS 实例内汇总和后续三维区域关联使用。像素类别图、实例掩码和 track ID 分别保留；后端需要的单像素 `instance_id` 及重叠像素归属由观测适配器生成，不代替原始实例掩码。KITTI05/10 正式缓存的无光流关联属于另一运行配置。[Seq09 实例跟踪实现](../特调地图/seq09_seed42_交付校验/evidence/annotation_scripts/run_instances.py) · [实际光流参数调用](../阶段2/动态语义Demo_设计/生成记录/KITTI09_300-499_KITTI17_0-199_服务器队列_20261107/server_queue.py)
- **为什么用**　判断“这是车”与“这辆车在动”需要不同信息。类别图给匹配筛选、高斯几何优化和语义融合提供类别信息，实例轮廓使 Pi³MOS 能对每一辆车单独做决定。
- **为什么能起作用**　实例轮廓把同一辆车的像素放在一起，光流辅助关联缓解相邻帧位移对掩码重叠的影响；track ID 仍可能断裂或误关联。类别和置信度为后端语义比较及离线对象关联提供支持。漏检会让车辆失去实例级判定入口，边界偏差会改变汇总和过滤范围。[Seq09 实例跟踪实现](../特调地图/seq09_seed42_交付校验/evidence/annotation_scripts/run_instances.py)

### 模块4. 车辆动静判定（Vehicle Motion State Classification）【已有方法＋团队适配】

- **工作流程**　使用冻结权重的 Pi³MOS，以真实连续八帧左目 RGB `[t−7, …, t]` 为输入。把模型最后一帧的 `dynamic_masks` 概率插值回当前左目原图尺寸，在实际支持的 `car / truck / bus / van` 原始实例掩码内取中位数。已采用的原始运动判定统一以 `score ≥0.50` 为 `raw_state=dynamic`，否则为 `static`；区间前七帧或无有效分数时为 `unknown`。这里的 0.50 是原始运动概率判定阈值，不是按地图选择的深度置信度阈值。模型推理不使用深度或 ORB 位姿，深度用于后续有效观测筛选与三维关联。[原始运动实现参考](../特调地图/seq09_seed42_交付校验/evidence/annotation_scripts/run_motion.py)
- **离线对象展示状态**　对象状态展示不直接显示上述逐帧 raw_state，而是在同一张 F1 语义地图上提取车辆三维区域，用实例 mask、相机及原始 RAFT 深度关联多帧观测；同区域同帧去重后，按配置进行间隔采样，用有效运动分数的中位数与静态、动态双阈值判定区域状态，中间区间或证据不足保留 uncertain。在符合短轨迹持续性假设时，可启用远处静态保持：已有连续可靠的远处静态证据，车辆靠近后才出现动态预测时，结合接近距离和观测支持决定是否保持静态。采样间隔、最小证据数、距离与保持条件按各地图的验证配置登记，不将单场景设置作为通用参数。每个区域只显示一个状态，标签落在该区域的实际高斯点上，uncertain 可在展示时隐藏。此步骤使用整段观测，是离线对象状态归并，不是逐帧在线状态机；尚无逐对象真值准确率验收。[对象配置参考](../特调地图/vehicle_state_experiment/reuse/seq09_c50s42_profile.json) · [部署清单参考](../阶段2/动态语义Demo_设计/T07_动态语义独立副本/scene-data/KITTI09_C50S42/KITTI09_ObjectStates/manifest.json)
- **阶段三像素接口**　后端适配时才将三类车辆状态写入其占有像素，并编码为 Static（0）、Unknown（1）、Dynamic（2），范围外为 Ignore（255）。该像素接口与 Seq09 的字符串 raw_state、离线对象 uncertain 分别说明。[阶段三 Pi³MOS 适配](../阶段3/S23_语义贡献实验_20261105/s23p_inputs.py)
- **为什么用**　语义分割会把停车和行驶的车辆都标成车，Pi³MOS 提供额外的时序运动分数。Seq09 展示再按三维车辆区域归并多个 track 的证据，减少同车重复标签和近处状态翻转；最终固定展示状态不表示已识别出真实起步、停车过程。
- **为什么能起作用**　多帧输入给模型利用时序变化的机会，掩码中位数能减弱少数边界错分和局部高分的影响。离线区域关联把同一地图车辆的多条轨迹证据归并，仍存在区域误合并和静态保持假设失效的风险。下列 S23-P 数据属于阶段三逐帧状态替换闭环，不是 Seq09 最终对象标签的准确率：KITTI05 稀疏投影整窗评分的召回率为 74.82%、精确率为 8.16%、静态误删为 10.85%；KITTI10 只有 847/1000 帧可评，跨窗独立识别判定为 `NOT_EVALUABLE`。[S23-P 归档回执](../阶段3/S23_语义贡献实验_20261105/archives/e93cbaafd8d5fec03f35aa9ded5ef2ad320bc16a32d90679f535326840306bee_local_receipt.json)

### 模块5. 动态车辆像素屏蔽（Dynamic Vehicle Pixel Masking）【团队方案】

- **工作流程**　将逐帧状态转成 `state != 2` 的允许掩码。开启过滤时，掩码限制位姿校正使用的参考帧和当前帧特征及其渲染验收区域，也限制新高斯反投影、建图的 RGB／深度损失和语义投票使用的像素。语义引导的几何优化也使用这张掩码。Unknown 和 Ignore 保留。输出是各环节可用的观测集合。 [动态过滤掩码实现](../阶段3/S23_语义贡献实验_20261105/semantic_runtime.py)
- **离线展示对应**　上述为阶段三在线屏蔽入口。所引用的展示原图建图未按车辆类别排除，也未消费运动状态过滤。曾生成的 V1/V2 是建图后派生副本：按语义车辆候选、实例 mask 和预测深度一致性累计动态票，V2 再补充高斯创建帧证据，并非 `state != 2` 的在线屏蔽。固定对象标签与旧清理输出分别管理；所引用场景已关闭旧清理，不能把它称为当前对象状态驱动的地图。[原图清单参考](../特调地图/seq09_seed42_交付校验/scene-data/KITTI09_F1/KITTI09_F1_manifest.json) · [场景配置参考](../阶段2/动态语义Demo_设计/T07_动态语义独立副本/源码/scene-config.kitti09-c50-s42.json) · [V2 后处理实现](../特调地图/seq09_seed42_交付校验/evidence/mapping_scripts/cleanup_v2.py)
- **为什么用**　动着的车不会一直待在地图的同一个位置。如果把车身像素当成稳定结构，它可以拉偏位姿、被写成一串车影，也可以让已有高斯学到错误颜色和深度。
- **为什么能起作用**　屏蔽操作直接阻断选中的像素进入对应、出生或损失。旧 S23 的 KITTI08 开发组实际少了 25 对 3D–2D 匹配和 4,027 个新高斯，证明过滤到达了计算入口。质量取决于被过滤的像素是否真的在动。该开发组的 ATE 增加 1.83%，共同 GT 相机下静态点 PSNR 下降 0.154 dB。该模块的作用范围是屏蔽观测，已写入地图的动态高斯清理和被遮挡背景恢复需要独立机制。 [D 开发对照](../阶段3/S23_语义贡献实验_20261105/D组动态对照_20261107.md)

### 模块6. 地图辅助位姿校正（Map-Assisted Pose Correction）【团队方案】

- **工作流程**　以最新选中位姿和 ORB 的相对运动形成当前预测。取可用的过去参考帧，用可信双目深度将参考 SIFT 像素反投影为 3D，与当前 SIFT 像素匹配。PnP/RANSAC 生成候选。用同一份更新前地图渲染预测与候选位姿，在相同可信支持上比较 RGB／深度残差，并检查变换幅度与连续不透明度质量保留率（≥ 0.98，不是可见像素数量占比）。候选通过才采纳，否则保留当前预测。选中位姿供建图和下一帧预测。 [MASS 六组对照](../阶段3/G30_恢复接续_v2_20261101_p44181/G30_六组结果与本轮收口_20261101.md)
- **为什么用**　逐帧使用 ORB 预测时，小误差可能随车程积累。把一处观测写进地图之前，系统需要判断当前相机位姿是否值得修正，也要保留证据不足时可回退的位姿。
- **为什么能起作用**　3D–2D 对应提供几何候选，旧地图渲染提供另一个验收条件。可见性门约束候选靠丢掉原本可见的像素来取得较低误差。G30 的 KITTI08 单种子开发窗中，MASS＋H3 相对 ORB＋H3 的 ATE 改善 14.58%，单帧平移 RPE 改善 0.98%，联合采用门未通过。KITTI03 的组合试验记录 800 次尝试中实际采纳 27 次，验证了反馈在新组合中执行。 [G30 结果](../阶段3/G30_恢复接续_v2_20261101_p44181/G30_六组结果与本轮收口_20261101.md)

### 模块7. 按类别筛选特征匹配（Feature Match Filtering by Semantic Class）【团队方案】

- **工作流程**　完成 SIFT 匹配与有效深度筛查后，读取参考端和当前端的像素类别。两端均为有效类别、置信度均 ≥ 0.80 且类别不同时，删除该对对应。其余对应继续进入 PnP/RANSAC。 [匹配筛选实现](../阶段3/S23_语义贡献实验_20261105/semantic_constraints.py)
- **为什么用**　车窗边缘、建筑边缘和路面纹理有时在局部看起来相似。让一对明显跨类别的高置信匹配参加位姿拟合，会给相机运动引入错误支持。
- **为什么能起作用**　语义类别补足了 SIFT 只有局部外观的信息，高置信双端门限制了低置信分割造成的删点。同一种类的误配依然交给几何校验，语义误分时也可能删真匹配。S23 有逐对删点和开发因子对照，仅启用类别一致性匹配筛选的 KITTI08 开发组 ATE 由 1.974 m 增至 2.007 m。现有证据支持筛选发生，整体收益尚未确立。 [T/TM 开发对照](../阶段3/S23_语义贡献实验_20261105/TM组联合对照_20261107.md)

### 模块8. 高斯地图增点与优化（Gaussian Primitive Insertion and Map Optimization）【已有方法＋团队适配】

- **工作流程**　在 SplaTAM 建图器中，从首帧有效深度反投影建立初始地图，首帧单独计数。后续建图帧根据渲染覆盖不足或深度残差找新点候选，再结合有效深度与配置的可靠性门。用帧号和种子确定的排名，每个后续建图帧最多选择 3000 个候选。S23 可在实际反投影时再与动态过滤掩码求交。选中相机在该次建图内固定，通过可微渲染对 RGB／深度残差做 Adam 更新，并按相同规则剪枝。当前受控路线关闭独立 clone/split 增殖。 [实现与归档索引](fyp_pipeline_audit.md#模块与文件依据)
- **离线展示对应**　候选预算是上述阶段三受控实现的规则，不能直接套给原 Demo mapper。所引用的展示建图固定 ORB 估计相机，深度置信配置按该地图选择，没有阶段三的候选硬上限，也未接入 MASS/H3 或语义几何损失；原有团队模块及组合实验保留，但不将其执行归给该展示图。[建图调用参考](../特调地图/tune_f1_seq09.py) · [Demo mapper 源码](../特调地图/seq09_seed42_交付校验/evidence/mapping_scripts/splatam_isolated.py)
- **为什么用**　车驶入新区域时，地图需要新增高斯；已经覆盖的区域需要用新观测细调。限制每帧新点能约束大场景的增长，同时把更多计算留给反复调整已有结构。
- **为什么能起作用**　米制反投影给新高斯提供初始三维位置，多帧渲染误差为位置、形状与外观提供约束。3000 上限直接限制后续每帧新增数量，最终点数还由首帧和剪枝决定。KITTI03 的 O3/M3 共用该上限，各完成 48,060 次建图更新，结束点数约 206 万。点数账本支持预算控制，地图质量由独立的渲染、几何和覆盖指标回答。

### 模块9. 长间隔关键帧回放（Keyframes Replaying）【团队方案】

- **工作流程**　每个建图帧保留 60 次更新。当存在帧号满足 `k ≤ t − 200` 的历史关键帧时，用固定种子选取历史目标替换索引 15、35、55 的原调度目标（索引从 0 开始）。回放沿用历史帧的 RGB、深度、置信度和已选位姿。回放关闭时沿用基础调度。若历史目标与基础目标相同，计为有资格的槽，实际目标保持相同。 [G14 调度与验收](../阶段3/G14_KITTI08长流三种子_20261027/G14_执行报告_20261027.md)
- **为什么用**　车开远以后，近期图像会不断影响共享地图，早期街景很少再被看到。给较早的关键帧留出少量更新机会，可以在有限预算内持续检查旧区域。
- **为什么能起作用**　旧视角重新产生 RGB／深度误差，能校正漂离旧观测的高斯，同时保留大部分常规更新。G14 的三种子长流配对中，早期原始 RGB PSNR 平均改善 3.303 dB，裁剪到显示范围后改善 1.831 dB，近期原始 RGB PSNR 平均下降 0.048 dB。这个结果对应 G14 的固定前端与缓存口径。后来的 KITTI13 和 KITTI03 则核验了地图接入离线精修前，历史关键帧回放确实触发。 [G14 三种子结果](../阶段3/G14_KITTI08长流三种子_20261027/G14_执行报告_20261027.md)

### 模块10. 多视角语义投票（Multi-View Semantic Voting）【团队方案】

- **工作流程**　离线展示在 F1 完成后，固定其点集、几何、不透明度与相机，遍历登记的 Mask2Former 标签帧。将高斯中心投影到对应图像，要求该高斯在该帧已创建、光栅化半径 >0、投影在画内；再按非天空类别、语义置信度、渲染 silhouette 和中心深度与渲染深度的一致性筛选，具体门槛由该地图配置登记。每次按 `opacity × exp(−深度差/容差) × 语义置信度` 向该高斯的 19 类证据累计票数，并记录观测次数；最大证据类别作为标签，无证据则为 unknown。这是中心投影与近似可见性加权，不是将每个像素的全部实际光栅化贡献反传回高斯。[融合实现参考](../特调地图/seq09_seed42_交付校验/evidence/annotation_scripts/fuse_semantic.py)
- **为什么用**　单张二维语义图会有遮挡和误分类，固定地图上的多视角证据可为同一个高斯形成较稳定的类别。输出与对应 F1 地图同几何、同 opacity、同点序的语义标签和语义 PLY，仅替换展示颜色，并为离线车辆三维区域划分提供输入；语义不是物体身份或运动真值。
- **为什么能起作用**　可见性与深度门控减少明显被遮挡高斯接收前景标签的机会，加权累计可减弱部分孤立误标，但仍受二维分割、位姿、近似遮挡和投影支持影响。得到标签的高斯比例表示语义覆盖，不是准确率；点数及覆盖结果按各地图单独记录。[同点集语义清单参考](../特调地图/seq09_seed42_交付校验/scene-data/KITTI09_F1_Semantic/semantic_manifest.json)
- **阶段三在线对应**　S23 另在每个非留出建图帧结束后按光栅化贡献融合，随增点、剪枝维护稳定 ID，每源帧只融合一次，回放不重复计票。该在线类别分布供模块11使用；其生命周期账本和稀疏 mIoU 不作为 Seq09 离线融合的评价。[S23 类别融合实现](../阶段3/S23_语义贡献实验_20261105/semantic_mapping.py) · [S23 正式汇总回执](../阶段3/S23_语义贡献实验_20261105/archives/f3cbf5f4527f4df72f43f59e10322c7743a15d8efb5676362142313692ca0876_local_receipt.json)

### 模块11. 语义约束的高斯几何优化（Semantically Constrained Gaussian Geometry Optimization）【团队方案】

- **工作流程**　渲染已有高斯在此前帧累积的类别分布，与当前 Mask2Former 类别比较。用置信度 ≥ 0.80、有效深度、足够的可见类别支持和动态过滤掩码确定有效像素。更新目标为当前帧时，在原 RGB／深度损失上加权叠加类别交叉熵梯度（权重 0.1），梯度只给高斯位置、尺度和旋转。当前帧的标签在优化结束后才进入投票。 [语义运行时](../阶段3/S23_语义贡献实验_20261105/semantic_runtime.py) · [语义几何约束损失](../阶段3/S23_语义贡献实验_20261105/semantic_mapping.py)
- **为什么用**　路面与路沿、车辆与背景有时颜色相近。只看颜色和深度时，一些投影错位的高斯也能得到相近的误差。类别边界给几何多一条检查线索。
- **为什么能起作用**　如果历史投票判为车辆的高斯投到了高置信道路像素，类别损失会给高斯的投影位置和形状一个调整方向。用此前投票与当前观测比较，建立了跨帧约束。S23 单独启用语义引导的几何优化时记录 2,895 次有效语义梯度，归档验证了梯度只落在几何参数上。该组共同 GT 相机下静态点 PSNR 下降 0.119 dB，语义梯度的执行证据与地图增益是两个不同的结果。 [M 开发对照](../阶段3/S23_语义贡献实验_20261105/M组开发对照_20261107.md)

### 模块12. 建图后颜色与不透明度精修（Post-Mapping Color and Opacity Refinement）【团队方案】

- **工作流程**　复制已完成的地图并读取该地图实际使用的相机轨迹，固定点集、相机、位置、尺度和旋转。循环回看登记的训练左目 RGB，在该次运行引用的固定深度可靠区域 `reliable_roi` 内计算渲染 RGB 的逐像素 L1，用 Adam 只更新颜色 `rgb_colors` 和不透明度 logit `logit_opacities`，学习率分别为 0.001、0.005。该 ROI 是深度可靠区域，不是车辆运动真值掩码，其来源与建图置信度阈值分别登记，不因更换建图阈值就假定它同步改变。训练帧集合与优化预算按各地图配置记录；输出精修副本，保存父地图哈希。离线展示的语义融合在 F1 后对实际点集重新运行，不把旧地图标签直接套给新地图。目标流程中已有语义标签须按原高斯 ID 维护；KITTI13、KITTI03 组合实验分别采用 260 帧×4 轮、801 帧×4 轮及各自的已选相机。[F1 训练器参考](../特调地图/seq09_seed42_交付校验/evidence/mapping_scripts/train_f1_seq04.py) · [F1 调用参考](../特调地图/tune_f1_seq09.py) · [新点集语义重建调用参考](../特调地图/build_seq09_demo_seed42.py)
- **为什么用**　先看到的街景和刚看到的街景，在在线建图时得到的优化机会不同。地图和相机定下来之后，可以统一回看原训练画面，进一步调整各高斯贡献的颜色与透明程度。
- **为什么能起作用**　同一批高斯在多个已知视角下反复渲染，颜色与不透明度可以逐步减少可靠区域的外观残差。KITTI03 的同父地图配对中，O3 的训练视图 ROI PSNR 从 19.93 升到 21.40 dB，M3 从 19.99 升到 21.53 dB。各对固定相机，12 个评分视图均是已见帧，各自按所登记的视角集合评分。这些结果支持外观拟合。精修固定几何和相机，改变不透明度仍可改变可见性及其渲染深度。另需用留出视角检验泛化。
