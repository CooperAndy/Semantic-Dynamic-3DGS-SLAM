# KITTI seq09 300–499 展示地图特调计划

## 已完成的首轮比较

现有 Demo F1 在选定的共同 ORB 视角中优于新跑的 B 和 TMD，因此本轮以现有 Demo F1 的 ORB 位姿、双目深度、建图和 800 步外观精修流程为基线。首轮 B、TMD 的 MASS 接受和 H3 回放均为 0；它们与原 Demo 的训练帧和精修不同，不能用于单独归因。

## 置信度筛选

- 固定相同的 200 帧、ORB 位姿、原双目深度与置信度图、建图迭代和 F1 精修，以 seed 0 比较建图深度阈值 0.50、原基线 0.60、0.70。原流程实际将 seed 阈值用于生成建图深度，单独保存的 loss 0.20 掩码未作为当前建图深度输入；本轮不声称调整了 loss 阈值。
- 原有 seed 0、0.60 F1 作为基线复用。其余两组在独立目录重建 200 帧地图并同样进行 800 步 F1；F1 精修使用固定的原始可靠区域掩码，保证各组优化和评价口径一致。
- 在相同 ORB 相机、背景、图像分辨率下，对固定的 13 个去重视角计算逐帧全图 PSNR、SSIM 和原可靠区域 PSNR；记录有效深度比例、地图点数与计算消耗。以 13 视角平均全图 PSNR 选取候选，同时检查 SSIM、各帧和渲染图；如发生明显质量或覆盖问题，保留基线并注明。
- 这些视角已经用于建图及 F1 精修，阈值和种子也在本场景上挑选；结果是展示用特调，不能作为独立泛化或几何精度结论。

## 种子与最终选择

- 将选出的阈值固定，按同样流程运行 seed 42 和 2026。确认配置中的随机种子确实传入建图代码，记录运行日志和配置；F1 的帧顺序固定。
- 比较该阈值 seed 0、42、2026 的同视角指标及图片，选展示候选。保留全部结果、配置、哈希和种子；最终汇报说明经过本场景及多次运行筛选。
- 地图和渲染图先保留在服务器，不自动下载；语义融合及车辆动态展示资产需要对选中的新地图重新关联和验证，不能直接沿用旧高斯索引。

## 执行检查

使用服务器独立目录，不覆盖现有地图或正式实验；运行前检查输入帧、深度格式和可用空间，运行时记录状态，失败时停止后续步骤并保留日志。不输入 GT 位姿或深度。原流程的 use_gt_poses=True 是读取固定外部位姿的代码分支，实际输入为 ORB 估计位姿。
